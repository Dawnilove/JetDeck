⌨️ 터미널

여러 탭·분할·터미널만 크게. 끊기면 자동 재연결하고 탭은 그대로.

📝 원격 편집

VS Code와 같은 Monaco 편집기. 젯슨에서 바뀐 파일은 덮어쓰기 전에 알려 줘요.

📊 시스템 모니터

코어별 CPU·GPU·메모리·온도·전력, JetPack·CUDA 버전. 라즈베리 파이 같은 일반 리눅스도 지원. 전원 모드 전환, 절전·재부팅, Wake-on-LAN.

▦ 분할 화면

연결을 최대 4개까지 한 화면에 나란히(좌우) 또는 바둑판으로. 탭을 끌어다 놓거나 분할 버튼으로.

🔑 SSH 키 마법사

이 PC의 키를 만들어 Device에 등록하고, 비밀번호 없이 접속하도록 한 번에 바꿔요.

🤖 ROS2 도구

토픽·노드 목록과 info, echo·hz 실시간, launch 파일 바로 실행.

🔧 시리얼 콘솔

SSH가 안 될 때의 비상구. 포트와 속도만 고르면 끝.

📁 파일 전송

내 PC ↔ 젯슨 양쪽 목록, 끌어다 놓기, 진행률·속도, 전송 취소.

🔀 포트 포워딩

로컬·원격·동적(SOCKS5). Jupyter·TensorBoard 프리셋, 접속하면 자동 시작.

✳️ MCP 연결

Claude·Cursor·Codex 등 AI가 젯슨에서 명령 실행·파일 편집. 위험한 명령은 내가 허용해야 실행. 연결되면 버튼에 불이 켜져요.

화면

설치

Windows 10 / 11

  1. 위 Windows 설치 파일을 받아 실행 (설치 없이 쓰려면 포터블)
  2. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행. 아직 코드 서명 인증서가 없어서 나오는 안내예요.
  3. 새 버전이 나오면 앱이 알아서 받아 두고 알려 줘요.

Linux (x64)

chmod +x JetDeck-*-x86_64.AppImage && ./JetDeck-*-x86_64.AppImage
  • 안 열리면 FUSE 2 설치: sudo apt install libfuse2 (Ubuntu 24.04는 libfuse2t64)
  • 비밀번호 저장에는 키링(GNOME Keyring 등)이 필요해요. 키링이 없으면 비밀번호를 저장하지 않으니 SSH 키를 쓰세요.

젯슨 쪽 준비물: SSH 서버만 켜져 있으면 돼요 (JetPack 기본 상태 그대로 OK).

3분 시작

  1. 새 연결에 젯슨 IP·사용자 이름·비밀번호 → 저장 후 연결
    • USB 케이블로 직접 연결했다면 192.168.55.1
    • IP를 모르면 오른쪽 주변 Jetson 찾기
  2. 처음 접속 때 뜨는 호스트 키 확인 → 지문을 보고 신뢰하고 연결
  3. 왼쪽에서 파일 열기 · 아래에서 명령 실행 · 오른쪽에서 상태 확인. 모든 기능은 Ctrl+Shift+P

🤖 ROS2 도구

왼쪽 활동 바의 ROS2 버튼. 젯슨의 ros2 명령을 SSH로 실행해 보여 줘요.

  • 토픽 — 발행·구독 노드, 메시지 보기(echo), 주기 측정(hz). 멈추거나 화면을 닫으면 젯슨 쪽 명령도 끝나요.
  • 노드 — 연결된 토픽·서비스
  • launch — 내 워크스페이스와 설치된 패키지의 launch 파일을 찾아, 확인 후 새 터미널 탭에서 ros2 launch

ROS 환경은 젯슨 ~/.bashrc의 source /opt/ros/<배포판>/setup.bash를 따라요.

🔧 시리얼 콘솔

  1. 젯슨 USB(장치 모드)를 PC에 꽂거나, USB-TTL 어댑터를 디버그 UART에 연결
  2. 새 연결 → 시리얼에서 포트와 속도(젯슨 기본 115200) → 저장 후 연결
  3. 케이블이 빠졌다 다시 꽂히면 자동으로 다시 연결해요.

Linux에서 "접근 권한이 없어요"가 뜨면 sudo usermod -aG dialout $USER 후 다시 로그인.

테마 17종

연결 관리 화면 오른쪽 위 테마 메뉴에서 바로 바뀌어요. 다시 시작할 필요 없어요. 모든 테마는 글자·터미널 색 대비 4.5:1 이상, 터미널과 편집기는 항상 불투명해요.

  • 에센셜 — 매일 쓰는 기본 4종
  • 컬러 무드 — 노을·숲·바다·종이·레트로 등 분위기 7종
  • 네온 사인 — 그라데이션 배경과 유리 패널, 연결 중일 때만 창 테두리가 빛나요
  • 마스코트 — 모모·볼트·두두가 연결 상태에 따라 표정을 바꾸고 한마디씩 해요
나머지 11종 보기 (에센셜 4 · 컬러 무드 7)
나만의 테마 만들기

테마 폴더에 JSON 파일을 넣고 앱을 다시 켜면 메뉴에 추가돼요. 같은 id면 기본 테마를 덮어써요.

  • Windows: %APPDATA%\nanoterm\themes\
  • Linux: ~/.config/nanoterm/themes/

기본 테마와 같은 형식(id, label, kind, ui, status, terminal.theme, editor, font)을 따르면 돼요. 네온 효과(ui.backgroundCss, effects)와 마스코트(mascot)도 같은 방식으로 정의해요.

AI에 연결하기 (MCP)

MCP를 지원하는 AI(Claude·Cursor·VS Code·Codex CLI·Gemini CLI 등)에게 "젯슨 온도 확인해 줘", "~/ros2_ws 빌드하고 오류 고쳐 줘"처럼 말하면 JetDeck을 통해 젯슨에서 바로 실행해요.

  1. 연결 관리 화면 위쪽 MCP 연결 버튼 — 연결된 AI가 있으면 버튼 옆에 초록 불이 켜져요
  2. 위쪽 탭에서 쓰는 AI를 고르면 그 AI에 맞는 설정이 나와요. 복사해서 붙여 넣고(또는 명령을 한 번 실행하고) 그 프로그램을 다시 켜기 — Claude Desktop·Claude Code·Cursor·VS Code·Codex CLI·Gemini CLI, 그 밖의 MCP 프로그램은 실행 명령만 알려 줘요
  3. "orin에 연결해서 GPU 온도 알려 줘"
도구하는 일
list_hosts · connect저장된 젯슨 목록·연결 (JetDeck에 탭이 열림)
run_command명령 실행 후 출력·종료 코드

🛡️ rm·sudo·reboot·kill·dd·apt·systemctl, >로 덮어쓰기 같은 명령은 JetDeck 화면에서 허용을 눌러야 실행돼요. JetDeck은 이 PC 안(127.0.0.1)에서 비밀 토큰을 가진 요청만 받아요.

🔒 데이터와 보안

  • 비밀번호는 OS 암호화로 이 PC에만 (Windows: DPAPI, Linux: 키링). 다른 PC로 복사해도 못 풀어요.
  • 호스트 키는 처음 접속 때 확인하고, 바뀌면 경고해요. ~/.ssh/known_hosts도 함께 읽어요 (쓰지 않음).
  • 저장 위치: Windows %APPDATA%\nanoterm\, Linux ~/.config/nanoterm/
  • 앱이 밖으로 보내는 건 젯슨과의 SSH 연결과 업데이트 확인(GitHub Releases) 뿐이에요.

증상확인할 것
"응답이 없어요"젯슨 전원·네트워크, 같은 공유기인지, IP가 바뀌지 않았는지
"인증 실패"사용자 이름·비밀번호. 키 인증이면 키 파일 경로
"비밀번호 로그인을 막아 두었어요"그 기기는 SSH 키로만 접속돼요. ① 등록된 키가 있으면 인증 방식을 "SSH 키"로 ② 없으면 ssh-keygen -t ed25519로 만든 뒤 id_ed25519.pub를 젯슨 ~/.ssh/authorized_keys에 추가 ③ 본인 젯슨이면 /etc/ssh/sshd_config.d/의 PasswordAuthentication no를 yes로 바꾸고 sudo systemctl restart ssh
암호 걸린 SSH 키ssh-add로 ssh-agent에 등록한 뒤 연결
ROS2 목록이 비어 있음노드가 실행 중인지, ~/.bashrc에 ROS setup.bash를 source하는 줄이 있는지
시리얼 "다른 프로그램이 쓰고 있어요"PuTTY·Arduino IDE가 같은 포트를 열고 있는지
시리얼 글자가 깨짐속도(baud). 젯슨 디버그 콘솔은 115200
시스템 모니터가 비어 있음Linux가 아니거나 /proc·/sys를 읽을 수 없는 기기 (젯슨이 아니어도 일반 리눅스는 표시돼요)
파일이 편집기로 안 열림5MB 초과, 바이너리, UTF-8이 아닌 파일은 열지 않아요 (원본 보호)
