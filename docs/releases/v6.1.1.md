# JetDeck 6.1.1

> **보안 후속 수정**이에요. 6.1.0(시리얼 읽기 권한)의 보안 리뷰에서 남았던 낮음 3건을 고쳤어요. 새 기능은 없어요.

5.x·6.x를 쓰고 있다면 앱을 켤 때 **자동으로 받아서** 알려 줘요. **다시 시작해서 업데이트**를 누르면 끝.

## 고친 것

- **같은 모델 보드를 바꿔 꽂아도 감지** — 시리얼 번호가 없는 보드(CH340 등)를 같은 포트 이름에 바꿔 꽂으면 6.1.0은 같은 장치로 봤어요. 이제 장치의 `pnpId`·`locationId`도 비교해서, 고른 뒤 바뀌면 "고른 포트가 바뀌었어요"로 막아요.
- **보이지 않는 글자 정리** — 포트 이름 속 방향 표시 글자(U+061C)를 지우고, 오류 문구의 포트 이름도 같은 정리를 거쳐요.
- **팩 검사 범위 맞춤** — `serial.read` 권한에서 `hupcl`·`rtscts`·`rtsMode`를 앱이 거부하고, JSON 스키마도 `port`·`path`·`device`·`write`·`dtr`·`rts`·`hupcl`·`rtscts`·`rtsMode`를 거부해서 편집기가 미리 알려 줘요. 안전에 미치는 영향은 없었어요.

## 확인한 범위

확인한 것: 자동 시험 557개, 타입 검사 통과. 장치 비교·보이지 않는 글자·금지 항목은 시험으로 고정했어요.

**확인하지 못한 것**:

- `pnpId`·`locationId` 값이 실제 장치와 드라이버에서 안정적인지(같은 보드를 같은 포트에 다시 꽂았을 때 값이 같은지). 이 값이 흔들리면 "고른 포트가 바뀌었어요"가 불필요하게 뜰 수 있어요.
- 포트 고르기 창 버튼에서 `&` 글자가 Windows 단축키 표시로 바뀌어 빠지는지는 고치지 않았고 확인하지도 않았어요.
- 6.1.0에서 확인하지 못한 항목(진짜 포트·실제 장치, OS 포트 고르기 창, 영어 화면 등)은 그대로예요. [6.1.0 노트](v6.1.0.md) 참고.
