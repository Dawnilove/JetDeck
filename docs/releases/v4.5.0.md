# JetDeck 4.5.0

> **기기 관리 확장** 업데이트예요. apt 업데이트, 디스크 정리, 전원·부팅 설정을 앱에서 하고, 화면 위쪽과 왼쪽 막대를 깔끔하게 정리했어요. 기기에는 여전히 아무것도 설치하지 않고 SSH로만 동작해요.

4.4.0 이하를 쓰고 있다면 앱을 켤 때 **자동으로 받아서** 화면 위쪽에 알려 줘요. **다시 시작해서 업데이트**를 누르면 끝.

## ✨ 새 기능

왼쪽 막대의 **기기 관리 → 업데이트·디스크·전원** 탭이에요. 바꾸는 작업은 모두 **확인창에서 실행할 명령을 그대로 보여 주고**, 설치·정리 작업은 **미리보기를 본 뒤에만** 실행돼요.

- **apt 업데이트** — 새 버전이 있는 패키지를 표로 보여 줘요. 목록 새로고침(`apt update`)과 모두 업그레이드(`apt upgrade`)는 확인창을 거쳐요. 업그레이드는 설치될 패키지 목록을 먼저 보여 줘요.
- **디스크** — 디스크 사용량 표, 고른 위치(홈·`/home`·`/var`·`/opt`·`/`) 아래의 **큰 폴더 15개**(보기만 해요), 그리고 안전하게 줄일 수 있는 정리 세 가지: **apt 내려받은 파일 비우기 · 안 쓰는 패키지 정리 · 시스템 로그 줄이기(200MB까지)**. 정리는 지울 것을 미리 보여 주고 확인한 뒤에만 해요. 내가 고른 폴더를 지우는 기능은 일부러 넣지 않았어요.
- **전원·부팅** — 현재 상태(부팅 방식·켜진 시각·재부팅 필요 여부·예약), **부팅 방식 바꾸기**(화면 있음/없음, 다음 부팅부터, 다시 바꿀 수 있어요), **재부팅·종료 예약**(5분·30분·1시간)과 **예약 취소**, 지금 재부팅·종료.
- **sudo** — 서비스 화면과 같은 방식이에요. 먼저 비밀번호 없이 시도하고, 비밀번호가 필요하면 **새 터미널에 명령을 넣어 줘요**. 앱은 비밀번호를 받지 않아요.

## 🧹 화면 정리

- **환경 설정 메뉴** — 맨 위에 흩어져 있던 언어·테마·마스코트·설정 내보내기/가져오기·진단 정보 저장을 메뉴 하나로 모았어요.
- **왼쪽 막대 7개** — 탐색기 · 시스템 모니터 · 개발·실행 환경(파일 검색·빌드·ROS2·Docker) · 연결·전송(포워딩·파일 전송) · 활동 · 기기 관리(서비스·기기 점검·업데이트·디스크·전원) · 화면·영상. 묶음 안 화면은 화면 위쪽 탭으로 오가요. **연결 관리**는 위쪽 버튼으로 옮겼어요.

## 🔧 만든 방식

기기 관리 도구의 명령·표시 방식·확인 문구는 코드가 아니라 **데이터 파일**(`src/main/packs/device.json`)에 적혀 있어요. 앱은 그 파일을 읽어 화면을 그리고 실행만 해요. 다음 5.0.0의 선언형 플러그인 팩과 같은 형식이라 그대로 옮겨 갈 수 있어요. 위험한 명령 규칙(읽기 항목에 쓰기 명령 금지, sudo는 단일 명령만, 정리는 미리보기 필수, 지우는 대상의 막힌 경로)은 파일을 읽을 때마다 검사해요.

## ⚠ 알아 두세요 (미확인)

- 실제 Jetson에서 **apt 설치·정리·재부팅 같은 바꾸는 작업은 실행해 보지 않았어요.** 가짜 SSH 서버로 확인 창·미리보기·명령 모양·비밀번호 필요 처리만 확인했고, 읽기 항목은 실제 기기 출력으로 한 번 더 확인할 예정이에요. 문제가 있으면 [이슈](https://github.com/Dawnilove/JetDeck/issues)로 알려 주세요.
- 업그레이드·안 쓰는 패키지 정리는 끝날 때까지 출력이 한꺼번에 나와요(진행 표시는 나중에).
- 영어 화면은 직접 눈으로 다 확인하지는 못했어요.
