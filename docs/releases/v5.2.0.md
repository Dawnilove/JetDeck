# JetDeck 5.2.0

> **플러그인 시계열 그래프** 업데이트예요. 팩이 읽기 명령을 되풀이해서 **숫자를 선 그래프로** 그려 줘요. 내 PC에서 코드는 여전히 실행되지 않고, 기기에는 아무것도 설치하지 않아요.

5.1.0을 쓰고 있다면 앱을 켤 때 **자동으로 받아서** 화면 위쪽에 알려 줘요. **다시 시작해서 업데이트**를 누르면 끝.

## ✨ 새 기능

- **시계열 그래프** — `display.type: "chart"` 항목은 `every`초마다 명령을 **한 번씩** 실행하고, 읽은 숫자를 선 그래프에 점으로 더해요. 카드에 선 이름·마지막 값·단위·눈금선이 보이고 **시작·멈춤·일시정지·지우기**가 있어요. **화면을 나가거나 연결이 끊기거나 앱을 닫으면** 멈춰요. 데이터는 앱 메모리에만 있고 파일에 쓰지 않아요.
- **새 공식 플러그인 "센서 그래프"** (모니터·성능 팩, 기본 켜짐) — **온도**(열 센서마다 선 하나) · **메모리**(전체·쓸 수 있음, MB) · **부하 평균**(1·5·15분) · **GPU 사용률**(젯슨) · **팬 속도**(젯슨). 모두 읽기 전용이고, 시작을 눌러야 돌아요. 자동으로 시작하는 그래프는 없어요.
- **읽는 방법을 팩에 적어요** — `match`(정규식)나 `split`(공백·탭·쉼표)으로 숫자를 읽고, `perLine`(줄마다 선 하나)이나 `series`(고정된 선 목록)로 선을 정해요. `scale`로 단위를 바꿀 수 있어요(밀리도 → ℃).
- **허용 창·플러그인 관리 창** — 머리말에 "그래프 N", 항목에 "그래프 N초마다" 표시가 생겼어요. `auto: true` 그래프는 "자동으로 돌아가는 것" 구역에 간격과 함께 보여요.
- **팩 만드는 법** — [docs/plugins](https://github.com/Dawnilove/JetDeck/tree/main/docs/plugins)에 그래프 절, 보안 요약, JSON Schema, 예제(온도·메모리·부하·내 학습 loss)를 추가했어요. 그래프를 쓰는 팩에는 `"minApp": "5.2.0"`을 적으세요.
- **모니터 기록** — 그래프 그리는 코드를 새 그래프와 함께 쓰도록 정리했어요. 모양과 동작은 그대로예요.

## ⚠ 바뀐 점 — 꼭 읽어 주세요

- **그래프는 앱이 읽기로 증명한 명령만** 쓸 수 있어요. 증명이 안 되면 항목이 팩에서 빠져요(경고만 뜨고 남는 일은 없어요). `sudo`·입력 칸·`params`·`preview`도 못 써요.
- 한 팩에서 **동시에 돌릴 수 있는 그래프는 5개**, 앱 전체로는 10개예요. 한도를 넘으면 카드에 안내가 떠요.
- 읽는 간격은 직접 설치하는 팩이면 **1초 이상**(공식 0.5초), 한 번 읽는 시간은 기본 10초·최대 30초예요. 앞 읽기가 안 끝났으면 건너뛰고, 느리면 간격을 늘리고, **연속 5번 실패하면 멈춰요**.
- 숫자를 하나도 못 읽으면 카드에 "읽을 수 있는 숫자가 없어요"와 출력 마지막 한 줄이 나와요(식을 고칠 때 도움이 돼요).
- 5.1 앱에서 `chart`를 쓴 5.2 팩을 열면 팩 전체가 거부되거나(`minApp`) 그 항목이 숨겨져요. 5.0·5.1 팩은 그대로 동작해요.
- 연결이 끊기면 그래프 카드가 사라지고, 다시 연결하면 점이 비어서 새로 시작해요. 플러그인 탭을 오가도 점이 지워져요.
- 눈금선에 세로 눈금 **숫자**는 안 그려요(머리말의 "○○까지"와 선 이름 옆의 마지막 값만 보여요).

## 확인하지 못한 것

- 가짜 SSH 서버로 **센서 그래프 5개가 모두 그려지는 것**(온도 2선·메모리 2선·부하 3선·GPU·팬)과 시작·멈춤, 동시 2개 한도 안내는 확인했어요. 센서 경로와 출력 모양은 젯슨(Orin급 1대)에서 **읽기 명령으로만** 확인했어요(온도·메모리·부하·GPU 사용률·팬 값을 읽고, 일부 열 센서는 값이 없어 건너뛰는 것도 봤어요).
- **실제 젯슨에서 앱의 그래프 카드를 직접 보지는 못했어요.** 다른 기종(Xavier·Nano·라즈베리 파이)에서 GPU·팬 경로가 다를 수 있고, 그러면 "읽을 수 있는 숫자가 없어요"가 떠요. 이상하면 이슈로 알려 주세요.
- 앱을 **강제 종료한 뒤 기기에 프로세스가 남지 않는지**는 확인하지 못했어요. 한 번 읽을 때마다 `timeout`이 붙은 짧은 명령이라 남을 가능성은 낮아요.
- 영어 화면, 밝은 테마의 선 색 구분, 그래프 8선·1000점 이상일 때의 속도, 설치판 업데이트 알림은 직접 다 보지 못했어요.
- 탐색기 배지는 5.3.0에서 나와요.
