# JetDeck 2.1.3

> Jetson이 아닌 기기에도 어색하지 않게 문구를 다듬고, AI 연결 불이 JetDeck을 다시 켜도 스스로 돌아오게 했어요.

2.1.2 이하를 쓰고 있다면 앱을 켤 때 **자동으로 받아서** 화면 위쪽에 알려 줘요. **다시 시작해서 업데이트**를 누르면 끝.

## ✨ 개선

- **작업 공간 화면에도 MCP 버튼과 연결 불** — 연결한 뒤의 작업 공간 화면 위쪽(연결 해제 버튼 옆)에 MCP 버튼이 생겼어요. AI가 연결되면 초록 불이 켜지고, 마우스를 올리면 어떤 AI인지 보여요. 눌러서 연결 방법을 볼 수도 있어요.
- **"Jetson" 전제 문구를 "Device"로 통일** — SSH로 접속되는 기기는 Jetson만이 아니라서, 연결 화면(**주변 Device 찾기**, **Device의 IP 주소와 계정 정보를 입력하세요**), 삭제·재부팅·종료 확인 창, 파일 전송·포트 포워딩·ROS2 화면, 첫 실행 가이드, 호스트 키 안내, MCP 설명을 모두 "Device" 기준으로 바꿨어요. 앱 이름 아래 부제는 **"Jetson에 특화된 SSH 클라이언트"** 로 바뀌었어요. 전원 모드·`tegrastats` 같은 Jetson 전용 기능은 그대로예요.

## 🛠 고친 점

- **AI 연결 불이 꺼진 채 남던 문제** — JetDeck을 껐다 켜면(업데이트 포함) 이미 연결돼 있던 AI가 연결 불에 다시 나타나지 않았어요. 이제 연결 프로그램이 JetDeck이 다시 켜진 것을 1초 안에 알아채고 스스로 다시 알려 줘요.

> **참고** 업데이트를 설치하는 동안 JetDeck 프로그램이 종료되면서 AI와의 연결이 한 번 끊길 수 있어요. 그럴 때는 Claude Code에서 `/mcp`로 다시 연결하고, Claude Desktop·Cursor 등은 그 프로그램을 다시 켜 주세요. (MCP 연결 창에도 같은 안내를 넣었어요.)

## ⬇ 내려받기

| 파일 | 용도 |
|---|---|
| `JetDeck-Setup-2.1.3.exe` | **Windows 설치판 (추천)** — 자동 업데이트 |
| `JetDeck-2.1.3-portable.exe` | Windows 설치 없이 실행 |
| `JetDeck-2.1.3-x86_64.AppImage` | Linux x64 (자동 업데이트) |

MCP 연결 기능 설명은 [2.1.0 릴리스 노트](https://github.com/Dawnilove/JetDeck/blob/main/docs/releases/v2.1.0.md)를 참고해 주세요.
