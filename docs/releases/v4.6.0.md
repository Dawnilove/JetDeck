# JetDeck 4.6.0

> **파일 편집** 업데이트예요. 기기에 저장된 파일과 내 편집 내용을 나란히 비교하고, 연결을 다시 열면 열어 두었던 편집기 탭이 돌아와요. 기기에는 여전히 아무것도 설치하지 않고 SSH로만 동작해요.

4.5.0 이하를 쓰고 있다면 앱을 켤 때 **자동으로 받아서** 화면 위쪽에 알려 줘요. **다시 시작해서 업데이트**를 누르면 끝.

## ✨ 새 기능

- **기기와 비교(diff)** — 편집기 위쪽 경로 줄의 **Device와 비교**를 누르면 기기에 저장된 파일(왼쪽)과 지금 편집 중인 내용(오른쪽)을 나란히 보여 줘요. 오른쪽은 비교 화면에서 그대로 고칠 수 있고 `Ctrl+S`로 저장해요. 같은 내용이면 "차이가 없어요"라고만 알려 줘요. 다시 누르면(**비교 닫기**) 편집기로 돌아와요.
- **저장 충돌은 비교부터** — 파일을 연 뒤에 기기에서 그 파일이 바뀌었으면, 저장할 때 곧바로 덮어쓰기를 묻지 않고 **달라진 부분을 먼저 보여 줘요.** 확인한 뒤 **덮어쓰기**를 누르면 내 내용으로 저장돼요. (기기의 내용이 내 내용과 같으면 충돌 없이 저장돼요.)
- **편집기 탭 복원** — 연결을 다시 열면(앱을 껐다 켠 뒤 포함) 그 기기에서 열어 두었던 **파일 탭과 보던 탭**이 돌아와요. 기기마다 따로, **이 PC의 앱 데이터에만** 파일 경로 목록을 기억해요. **저장하지 않은 내용은 기억하지 않아요.** 그 사이 지워진 파일은 조용히 건너뛰어요.

## ⚠ 알아 두세요

- 탭 복원은 연결이 열린 뒤 파일을 하나씩 읽어 와서, 탭이 많으면 몇 초 걸릴 수 있어요(최대 30개까지 기억).
- 좁은 창에서는 비교 화면이 위아래 겹친 한 줄 보기로 나올 수 있어요(편집기 폭에 따라 자동).
- 영어 화면은 직접 눈으로 다 확인하지는 못했어요. 문제가 있으면 [이슈](https://github.com/Dawnilove/JetDeck/issues)로 알려 주세요.
