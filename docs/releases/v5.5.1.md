# JetDeck 5.5.1

> **MCP 오토파일럿**과 **GPU·메모리 클럭 표시**를 더한 업데이트예요.

5.5.0을 쓰고 있다면 앱을 켤 때 **자동으로 받아서** 화면 위쪽에 알려 줘요. **다시 시작해서 업데이트**를 누르면 끝.

## ✨ 새 기능

- **MCP 오토파일럿 (전문가 모드, 기본 꺼짐)** — MCP 설정 창의 스위치, `--autopilot` 실행 옵션, `JETDECK_AUTOPILOT=1` 환경 변수로 켜요. 켜면 AI의 `run_command`가 승인 창 없이 실행돼요. 우선순위는 실행 옵션 > 환경 변수 > 설정 파일(`autopilot.json`) > 기본값이에요.
- **승인 알림** — 오토파일럿이 꺼져 있을 때 승인 요청이 오면 데스크톱 알림이 뜨고 창이 깜빡여요. 다른 창에서 일해도 요청을 놓치지 않아요.
- **GPU·메모리 클럭** — 시스템 모니터에 `GPU · 1020 MHz`, `메모리 · 3199 MHz`처럼 실시간 클럭이 보여요. 기기의 읽기 전용 sysfs 값을 읽어요.

## ⚠ 바뀐 점 — 꼭 읽어 주세요

- **오토파일럿을 켜면 `sudo`, `rm` 같은 위험한 명령도 확인 없이 실행돼요.** AI의 실수를 되돌릴 수 없어요. 켠 상태는 저장되어 다시 시작해도 유지돼요.
- 오토파일럿은 `run_command`에만 적용돼요. **터미널 읽기 승인은 켜도 계속 직접 허용해야 해요.** 파일 쓰기 제한과 명령 검사는 그대로예요.
- 오토파일럿을 켜는 순간 이미 기다리던 `run_command` 요청은 바로 허용돼요. 기다리던 터미널 읽기 요청은 허용되지 않아요.

## 확인한 범위

확인한 것:

- 자동 시험 407개, 타입 검사, 영어 사전 검사, 빌드 통과.
- 모니터의 셸 조각이 파일이 없을 때 빈 값을 내는 것을 가짜 파일로 확인했어요.

**확인하지 못한 것**:

- 실제 Jetson에서 클럭 표시 (코드 기여자는 Jetson Orin Nano Super에서 확인했다고 알려 왔어요. 이 릴리스에서 다시 확인하지는 않았어요).
- 오토파일럿 켜기·끄기 화면과 알림의 눈 확인, 설치판 업데이트 알림.
