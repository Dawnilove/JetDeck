# JetDeck 2.1.0

> Claude뿐 아니라 Cursor·VS Code·Codex 등 MCP를 쓰는 AI를 연결할 수 있고, 연결되면 버튼에 불이 켜져요.

2.0.x를 쓰고 있다면 앱을 켤 때 **자동으로 받아서** 화면 위쪽에 알려 줘요. **다시 시작해서 업데이트**를 누르면 끝.

## ✨ 새로운 점

- **MCP 연결 (이름 변경)** — 연결 관리 화면 위쪽 버튼이 "Claude 연결"에서 **"MCP 연결"** 로 바뀌었어요.
- **AI별 연결 안내** — 창 위쪽 탭에서 Claude Desktop · Claude Code · Cursor · VS Code · Codex CLI · Gemini CLI · 기타를 고르면, 그 AI에 맞는 설정(JSON 또는 명령)이 이 PC 경로가 채워진 채로 나와요. 복사해서 붙여 넣으면 끝.
- **연결 불** — AI가 JetDeck에 접속하면 버튼 옆에 **초록 불**이 켜지고, 마우스를 올리면 `Cursor 연결됨`처럼 어떤 AI인지 보여 줘요. 연결 창 맨 위에도 같은 상태가 나와요. 그 AI를 끄면 불도 꺼져요.
  (예전에는 연결이 됐는지 안 됐는지 알 방법이 없었어요.)

> Claude Desktop·Claude Code 외의 AI는 각 프로그램의 공식 설정 형식에 맞춰 안내했어요. 아직 실제 기기에서 하나하나 확인하지는 못했으니, 안 되는 게 있으면 [이슈](https://github.com/Dawnilove/JetDeck/issues)로 알려 주세요.
