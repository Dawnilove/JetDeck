# JetDeck 5.1.0

> **플러그인 2단계** 업데이트예요. 팩이 **끝나지 않는 출력을 실시간으로** 보여 주고, **입력 칸**을 가질 수 있어요. 내 PC에서 코드는 여전히 실행되지 않고, 기기에는 아무것도 설치하지 않아요.

5.0.0을 쓰고 있다면 앱을 켤 때 **자동으로 받아서** 화면 위쪽에 알려 줘요. **다시 시작해서 업데이트**를 누르면 끝.

## ✨ 새 기능

- **흐르는 출력(실시간 로그 카드)** — `mode: "stream"` 항목은 `journalctl -f` 같은 명령의 줄을 바로 보여 줘요. **시작·멈춤·지우기·복사·찾기·일시정지·따라가기**가 있고, 위쪽에 줄 수·속도·시간이 보여요. **화면을 나가거나 연결이 끊기거나 앱을 닫으면** 기기의 명령도 같이 끝나요(Ctrl-C → 3초 뒤 채널 닫기 → 최대 실행 시간). 출력이 너무 빠르거나(초당 1MB) 20MB를 넘으면 스스로 멈춰요.
- **입력 칸(폼)** — 팩 항목에 선택·글자·숫자·경로·체크 칸을 넣을 수 있어요. 값은 **따옴표로 감싼 단어 하나**로만 명령에 들어가고, 맨 앞 `-`·줄바꿈·제어 문자는 거부돼요. 앱은 **실행할 때마다 값을 채운 명령을 다시 분석**해서, 값 때문에 위험해지면(예: 민감한 경로) 확인창을 띄워요. 확인한 명령과 실제 실행하는 명령이 같은지도 앱이 한 번 더 비교해요.
- **기기에서 불러오는 선택지** — `ros2 topic list` 같은 읽기 명령의 출력이 선택지가 돼요. 카드를 열 때와 새로고침을 누를 때 실행돼요.
- **새 항목: 서비스 로그 따라 보기** — 기기 관리 → 로그 보기 탭에서 서비스를 고르면 `journalctl -f`로 새 로그를 계속 보여 줘요(기본 켜짐).
- **새 공식 팩: ROS2 실시간 보기(베타, 기본 꺼짐)** — 토픽을 고르면 메시지(echo)나 발행 속도(hz)를 계속 보여 줘요. 내장 ROS2 화면은 그대로이고, 비교해 보려고 나란히 넣은 베타예요. 플러그인 관리에서 켜면 허용 창이 떠요.
- **허용 창·플러그인 관리 창** — "누르지 않아도 자동으로 실행되는 것" 구역(기기에서 목록 불러오기, `auto` 항목)과 **실시간·입력** 표시, 입력 자리 `{이름}` 강조가 생겼어요.
- **팩 만드는 법** — [docs/plugins](https://github.com/Dawnilove/JetDeck/tree/main/docs/plugins)에 스트림·입력 폼·`from`·`minApp` 설명, 보안 문서, JSON Schema, 예제(실시간 보기)를 추가했어요. 새 기능을 쓰는 팩에는 `"minApp": "5.1.0"`을 적으세요.

## ⚠ 바뀐 점 — 꼭 읽어 주세요

- 실시간 항목은 **읽기로 인정된 끝나지 않는 명령**(`journalctl -f`, `tail -f`, `dmesg -w`, `top -b`, `iostat`, `mpstat`, `tegrastats`, `ros2 topic echo|hz|bw|delay`, `ip monitor`, `udevadm monitor`)만 묻지 않고 시작해요. 그 밖의 명령은 실시간이어도 확인창을 거쳐요.
- 실시간 항목에는 `sudo`와 `auto`를 쓸 수 없고, 실행 중인 스트림은 팩당 2개·앱 전체 4개까지예요.
- 5.0.0 앱에서 5.1 팩을 열면 새 기능을 쓴 항목은 숨겨지거나(“새 버전 앱이 필요해요”) 팩 전체가 거부돼요. 더 위험하게 실행되는 일은 없어요.
- 5.0.0 팩은 그대로 동작해요.
- 여러 줄에 걸친 비밀(로그에 찍힌 개인 키 등)은 줄마다 가려져서 못 가릴 수 있어요. 로그에 비밀이 찍히는 서비스는 조심하세요.

## 확인하지 못한 것

- 젯슨에서 `journalctl -f`는 멈춤 뒤, `ros2 topic hz`는 연결을 닫은 뒤 **기기에 프로세스가 남지 않는 것**을 확인했어요. 다른 명령·기기·앱 강제 종료는 확인하지 못했고, 메시지가 실제로 나오는 토픽의 echo·hz 출력도 직접 보지 못했어요. 이상하면 이슈로 알려 주세요.
- 영어 화면 전체, 설치판 업데이트 알림, 스트림 확인창(바꿈 이상 스트림) 클릭 흐름은 직접 다 보지 못했어요.
- 그래프·탐색기 배지는 5.2.0에서 나와요.
