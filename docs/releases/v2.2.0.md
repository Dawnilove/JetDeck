# JetDeck 2.2.0

> 연결을 한 화면에 나란히 보는 **분할 화면**, 라즈베리 파이 같은 **일반 리눅스 모니터**, **JetPack·CUDA 버전 표시**, **SSH 키 마법사**.

2.1.x를 쓰고 있다면 앱을 켤 때 **자동으로 받아서** 화면 위쪽에 알려 줘요. **다시 시작해서 업데이트**를 누르면 끝.

## ✨ 새로운 점

### ▦ 분할 화면 — 여러 기기를 한 화면에
- 연결이 2개 이상이면 탭 막대 오른쪽에 **분할** 버튼이 생겨요. 같이 볼 연결을 고르면(최대 4개) 한 화면에 나란히 보여요.
- **탭을 끌어서** 작업 화면 위에 놓아도 분할돼요. 놓은 쪽(왼쪽·오른쪽)에 칸이 생겨요.
- 배열은 **좌우로 나열**(기본)과 **바둑판**(2칸은 위아래, 3칸은 위 2 + 아래 1, 4칸은 2×2) 중에서 골라요.
- 각 칸은 터미널 중심의 간소한 보기예요. 탐색기·모니터는 접혀 있고 칸 안에서 펼칠 수 있어요. 선택한 칸에는 테두리가 보이고 단축키는 그 칸에만 먹어요.
- **칸 닫기**로 한 칸만 빼고(연결은 그대로 유지), **분할 해제**로 한 화면으로 돌아와요. 분할에서 빠지면 접어 두었던 패널이 원래대로 돌아와요.
- 지금은 SSH 연결만 분할할 수 있어요 (시리얼은 제외).

### 📊 시스템 모니터가 젯슨 밖에서도
- `tegrastats`가 없는 기기(라즈베리 파이 5 같은 일반 리눅스)도 `/proc`·`/sys`에서 읽어 **CPU 코어별 사용률·클럭, 메모리, 온도**를 보여 줘요. 젯슨 전용 항목(GPU·전력·전원 모드)은 해당 기기에서만 나와요.
- **기기 이름 · JetPack · CUDA 버전**을 모니터 위쪽에 표시해요. (예: `Jetson Orin Nano … · JetPack 7.2.1 · CUDA 13.2.2`, 라즈베리 파이는 기기 이름만)

### 🔑 SSH 키 마법사
- 연결 화면에서 인증 방식이 **비밀번호**일 때 **"SSH 키로 바꾸기 (키 등록 마법사)"** 버튼이 생겨요.
- 누르면 이 PC의 키(`~/.ssh/id_ed25519`, 없으면 새로 만들어요 — 있는 키는 덮어쓰지 않아요)를 Device의 `~/.ssh/authorized_keys`에 등록하고, 그 키만으로 접속되는 것까지 확인한 뒤 인증 방식을 SSH 키로 바꿔 줘요.

> 라즈베리 파이는 시스템 모니터 값 형식을 실제 기기에서 읽어 확인했어요. 분할 화면은 같은 젯슨에 연결 두 개를 열어 확인했고, 라즈베리 파이와 젯슨을 함께 놓은 분할은 직접 확인하지 못했어요. 이상한 점이 있으면 [이슈](https://github.com/Dawnilove/JetDeck/issues)로 알려 주세요.

## ⬇ 내려받기

|---|---|
| `JetDeck-Setup-2.2.0.exe` | **Windows 설치판 (추천)** — 자동 업데이트 |
| `JetDeck-2.2.0-portable.exe` | Windows 설치 없이 실행 |
| `JetDeck-2.2.0-x86_64.AppImage` | Linux x64 (자동 업데이트) |

젯슨에서 바로 실행하는 arm64판은 2.2.1로 준비 중이에요.
