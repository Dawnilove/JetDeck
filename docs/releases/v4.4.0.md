# JetDeck 4.4.0

> **작업 편의** 업데이트예요. 터미널 출력 검색·로그 저장, 문제 신고용 진단 정보, 설정 가져오기 덮어쓰기가 들어왔어요. 기기에는 여전히 아무것도 설치하지 않고 SSH로만 동작해요.

4.3.0 이하를 쓰고 있다면 앱을 켤 때 **자동으로 받아서** 화면 위쪽에 알려 줘요. **다시 시작해서 업데이트**를 누르면 끝.

## ✨ 새 기능

- **터미널 출력 검색** — 터미널 위쪽 **돋보기**(또는 명령 팔레트의 "터미널 출력 검색")로 스크롤백 안의 글자를 찾아요. Enter·↑↓로 이동하고, 한글·이모지가 섞인 줄도 맞게 표시돼요. 가장 최근 출력부터 찾아요.
- **터미널 로그 저장** — 터미널 위쪽 **저장 버튼**으로 터미널 내용을 `.log` 파일로 저장해요(스크롤백 5000줄까지). 내 터미널의 기록이라 비밀 가리기는 하지 않으니 공유 전에 확인해 주세요.
- **진단 정보 저장** — 연결 관리 화면의 **진단 정보 저장**으로 문제 신고에 붙일 정보를 파일로 만들어요. 앱·OS 버전, 호스트 개수와 종류, AI 요청 목록(도구·상태·시간만), 최근 앱 경고·오류 줄이 들어가고, **기기 이름·주소·사용자·키 경로·비밀번호는 넣지 않아요.** 로그 줄의 비밀처럼 보이는 값·IP·MAC·내 PC 경로는 가려요.
- **설정 가져오기 덮어쓰기** — 설정 가져오기 옆 **같은 것은 덮어쓰기**를 켜면, 같은 주소·사용자의 호스트와 이름이 같은 스니펫을 가져온 것으로 바꿔요. 저장된 비밀번호와 이 PC의 키 경로는 그대로 두고, 비밀이 가려진 스니펫은 덮어쓰지 않아요.
- **편집기 빈 화면 바로가기** — 열린 파일이 없을 때 최근 파일·도구와 함께 **단축키 목록**을 보여 줘요.

## 🔤 이름·문구
- **카메라** 화면 이름이 **영상 입력 미리보기**로 바뀌었어요(USB 카메라 등 영상 입력 장치).
- 앱 소개 문구가 "Jetson에 특화된, 모든 리눅스 기기를 위한 SSH 클라이언트"로 바뀌었어요.

## ⚠ 알아 두세요 (미확인)
- 로그 저장·진단 정보 저장·설정 가져오기의 **저장·열기 창 흐름**, 영어 화면, 한글이 섞인 줄의 검색 표시를 직접 눈으로 다 확인하지는 못했어요. 문제가 있으면 [이슈](https://github.com/Dawnilove/JetDeck/issues)로 알려 주세요.
- 터미널 검색은 줄바꿈으로 이어진 줄에 걸친 글자를 못 찾을 수 있어요. 진단 정보의 비밀 가리기도 패턴 기반이라 모든 비밀을 막지는 못하니, 공개 이슈에 붙이기 전에 한 번 훑어봐 주세요.
