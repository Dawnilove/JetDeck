# JetDeck 4.0.0

> 2.2 이후 **새 기능이 한꺼번에** 들어왔어요. 폴더 전송, ROS2 서비스·파라미터·bag, Docker, 기기 화면 보기, 여러 기기 대시보드, 카메라 미리보기, X11 화면, 그리고 **영어 화면**까지. 기기에는 여전히 아무것도 설치하지 않고 SSH로만 동작해요.

2.2.2 이하를 쓰고 있다면 앱을 켤 때 **자동으로 받아서** 화면 위쪽에 알려 줘요. **다시 시작해서 업데이트**를 누르면 끝.

## ✨ 새 기능

### 파일·명령
- **폴더 통째 전송 (2.3)** — 폴더를 올리고 내려받아요(하위 폴더·빈 폴더 포함). 파일은 **동시에 4개**까지 전송해요.
- **명령 스니펫 (2.3)** — 자주 쓰는 명령을 저장해요. 여러 줄·입력만(실행 안 함) 모두 되고, 팔레트에서 바로 실행해요.

### ROS2 (2.4)
- **서비스** — 목록, 요청 뼈대 자동 채우기, 호출
- **파라미터** — 노드별 읽기·설정
- **bag** — 목록·정보·재생·녹화(녹화는 새 터미널 탭)

### 원격 화면
- **VNC·RDP 외부 실행 (2.5)** — 기기별로 종류·포트를 정하고, "SSH 터널로 연결"(기본 켬)을 쓰면 작업 공간의 **원격 화면** 버튼 한 번으로 터널을 열고 `mstsc`/VNC 뷰어를 실행해요.
- **기기 화면 보기 (2.8)** — JetDeck 안에서 기기의 데스크톱을 바로 봐요(VNC, SSH 터널 경유). VNC 서버가 꺼져 있으면 켜는 방법을 안내해요. 서버 설치는 직접 해야 해요.
- **X11 화면 (3.1)** — 연결 설정의 "X11 화면"을 켜면 기기의 X11 프로그램(`xeyes`, `rviz2`, `rqt` 등) 창을 **이 PC의 X 서버**로 띄워요. X 서버(VcXsrv 등)가 필요하고, 없으면 설치·실행 방법을 설정 화면에서 안내해요.

### 기기 관리
- **Docker 패널 (2.6)** — 컨테이너·이미지 목록, 시작·정지·재시작·삭제(확인 창), 로그 보기(실시간은 새 터미널). Docker가 없거나 권한이 없으면 안내만 해요.
- **모니터 기록·그래프 (2.7)** — 최근 1시간 CPU·GPU·메모리·온도 그래프, **CSV 내보내기**
- **프로세스 목록·종료 (2.7)** — 내 계정의 프로세스를 보고 종료해요(종료 → 안 되면 강제 종료, 각각 확인)
- **AI 활동 보기 (2.7)** — Claude·Cursor 같은 AI가 JetDeck으로 보낸 요청 기록(비밀 값은 가림)과, **다른 SSH 접속**에서 일어나는 접속·명령 관찰(설정에서 끌 수 있어요). 그래프에 AI가 작업한 구간이 음영으로 표시돼요.
- **여러 기기 대시보드 (2.9)** — 저장한 기기마다 연결 상태·CPU·GPU·메모리·온도·전력 카드를 한눈에, 카드를 누르면 그 기기로 이동해요. "연결 안 된 기기 모두 연결" 버튼도 있어요.
- **카메라 미리보기 (3.0)** — 기기에 연결된 USB 카메라를 장치·해상도·fps를 골라 JetDeck 안에서 실시간으로 봐요(기기의 `gst-launch-1.0` 사용). 정지하거나 화면을 벗어나면 기기 쪽 프로세스도 같이 종료돼요.

### 🌐 영어 화면 (4.0)
- 화면 위쪽의 언어 버튼으로 **한국어 ↔ English** 를 바꿔요. 메뉴·안내·오류 문구, 메인 프로세스에서 나오는 문구까지 번역돼요.
- 언어를 바꾸면 화면을 다시 불러오기 때문에 **열린 연결이 닫혀요**. 바꾸기 전에 확인 창이 떠요.

## 🛠 다듬은 점 (출시 전 점검)
- 언어 전환 버튼이 실제로는 화면을 새로 불러오지 못하던 문제를 고쳤어요.
- 카메라·ROS echo/hz·VNC 터널을 시작하자마자 멈췄을 때 기기에 남던 프로세스, 카메라 프레임 메모리 누수를 고쳤어요.
- Device 화면 2개 동시 연결, 다른 SSH 접속 관찰을 끄면 '실행 중'으로 남던 기록, VNC 포트 설정 반영, bag 이름 처리, Docker 재연결·확인 문구, 대시보드 목록을 고쳤어요.
- 영어 전원 버튼 문구(Shut down), 가이드·명령 팔레트(프로세스·AI 활동·MCP·언어 등 항목 추가)·연결 폼 보완.

## ⚠ 알아 두세요 (미확인)
- 실제 VNC·RDP 서버 연결, 고해상도·YUYV·CSI 카메라, `rviz2`·`rqt`(기기에 따로 설치해야 함), 실제 AI 이름 표시, 기기 2대 이상 동시 대시보드, 최소 창 크기(960×600) 등은 직접 확인하지 못했어요. 문제가 있으면 [이슈](https://github.com/Dawnilove/JetDeck/issues)로 알려 주세요.
- 카메라·VNC 등은 기기에 해당 도구(`v4l2-ctl`, `gst-launch-1.0`, VNC 서버)가 있어야 해요. 없으면 설치 방법을 안내해요.
