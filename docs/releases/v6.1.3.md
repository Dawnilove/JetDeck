# JetDeck 6.1.3

> **보안 후속 수정**이에요. 6.0.0 보안 리뷰의 낮음 항목 중 마지막 1건(#11)을 고쳤어요. 새 기능은 없어요.

5.x·6.x를 쓰고 있다면 앱을 켤 때 **자동으로 받아서** 알려 줘요. **다시 시작해서 업데이트**를 누르면 끝.

## 고친 것

- **폴더 보기 읽기 상한** — 팩의 폴더 보기(`list`)는 Device가 보내는 항목을 끝까지 모은 뒤 2000개로 잘랐어요. 악성 Device가 항목을 끝없이 보내면 앱 메모리가 늘 수 있었어요. 이제 폴더를 열어 2001개까지만 읽고 멈춰요. 읽기 전체에 10초 시간 상한도 있어요.
- **정렬 범위** — 항목이 2000개를 넘는 폴더는 처음 읽은 2001개 안에서 정렬해요. 이 경우 화면에 "더 있음" 표시가 떠요.

## 확인한 범위

확인한 것: 자동 시험 560개, 타입 검사 통과. 코어가 Device에 상한(2001)을 넘겨 주는 것은 시험으로 고정했어요.

**확인하지 못한 것**:

- 진짜 SFTP 서버에서 `opendir`·`readdir` 동작(실기기·Electron 화면).
- 10초 시간 상한이 실제로 걸리는 경로. 시험하지 않았어요.
