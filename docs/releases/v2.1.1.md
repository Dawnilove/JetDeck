# JetDeck 2.1.1

> MCP 연결 창에서 Cursor·Gemini 설정 파일 경로가 잘못 보이던 문제를 고치고, 창을 더 편하게 다듬었어요.

2.1.0 이하를 쓰고 있다면 앱을 켤 때 **자동으로 받아서** 화면 위쪽에 알려 줘요. **다시 시작해서 업데이트**를 누르면 끝.

## 🛠 고친 점

- **Cursor·Gemini 설정 파일 경로** — 안내 문구에 `.cursormcp.json`, `.geminisettings.json`처럼 `\`가 빠져 보이던 문제. 이제 `.cursor\mcp.json`, `.gemini\settings.json`으로 바르게 나와요.
- **탭 줄이 움직이던 문제** — AI 탭을 바꿀 때마다 창 높이가 달라져 탭 줄이 위아래로 움직였어요. 이제 창이 위쪽에 고정돼 탭 자리가 그대로예요. 탭도 4칸 + 3칸으로 고르게 놓았어요.
- **연결된 AI 이름** — `claude-ai`처럼 프로그램 내부 이름이 보이던 것을 `Claude Desktop`처럼 알아보기 쉬운 이름으로 보여 줘요.
- **안내 문구** — JetDeck을 AI보다 나중에 켰을 때는 AI가 JetDeck 도구를 한 번 써야 불이 켜진다는 점을 문구에 넣었어요.
- **작은 편의** — "복사했어요" 표시가 2초 뒤 원래대로 돌아오고, 창을 다시 열면 마지막에 고른 AI 탭이 열려요.

## ⬇ 내려받기

| 파일 | 용도 |
|---|---|
| `JetDeck-Setup-2.1.1.exe` | **Windows 설치판 (추천)** — 자동 업데이트 |
| `JetDeck-2.1.1-portable.exe` | Windows 설치 없이 실행 |
| `JetDeck-2.1.1-x86_64.AppImage` | Linux x64 (자동 업데이트) |

MCP 연결 기능 설명은 [2.1.0 릴리스 노트](v2.1.0.md)를 참고해 주세요.
