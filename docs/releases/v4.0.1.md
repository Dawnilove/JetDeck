# JetDeck 4.0.1

> 업데이트하면 **바뀐 점을 앱에서 바로** 볼 수 있어요. 영어 화면도 더 자연스러워졌어요.

4.0.0을 쓰고 있다면 앱을 켤 때 **자동으로 받아서** 화면 위쪽에 알려 줘요. **다시 시작해서 업데이트**를 누르면 끝.

## ✨ 새로 생긴 것

- **업데이트 내용** — 업데이트한 뒤 처음 켜면 이번에 바뀐 점을 창으로 보여 줘요. 여러 버전을 건너뛰어 올려도 그 사이 바뀐 점을 한 번에 볼 수 있어요.
  연결 관리 화면의 **업데이트 내용** 버튼, 명령 팔레트(`Ctrl+Shift+P` → "업데이트 내용 보기")로 언제든 다시 열 수 있어요.

## 🛠 다듬은 점

- **Device 화면 탭은 VNC 연결에서만** — VNC로 설정하지 않은 연결에는 탭과 팔레트 항목이 보이지 않아요.
- **영어 화면** — 어색한 문장을 자연스럽게 고치고 용어를 통일했어요. 테마 17종 이름도 영어로 보여요.
- **사이트 갤러리** — 모니터 기록·프로세스·카메라 미리보기 화면을 [사이트](https://dawnilove.github.io/JetDeck/)에 추가했어요.

## ⬇ 내려받기

| 파일 | 용도 |
|---|---|
| `JetDeck-Setup-4.0.1.exe` | **Windows 설치판 (추천)** — 자동 업데이트 |
| `JetDeck-4.0.1-portable.exe` | Windows 설치 없이 실행 |
| `JetDeck-4.0.1-x86_64.AppImage` | Linux x64 (자동 업데이트) |
| `JetDeck-4.0.1-arm64.AppImage` | Linux arm64 (Jetson 등, 자동 업데이트) |

4.0의 새 기능은 [4.0.0 릴리스 노트](v4.0.0.md)를 참고해 주세요.
