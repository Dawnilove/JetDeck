# JetDeck 2.2.1

> 젯슨 본체에서 바로 쓸 수 있는 **Linux arm64판**을 추가했어요.

2.2.0 이하를 쓰고 있다면 앱을 켤 때 **자동으로 받아서** 화면 위쪽에 알려 줘요. **다시 시작해서 업데이트**를 누르면 끝.

## ✨ 새로운 점

- **Linux arm64 AppImage** — Jetson(aarch64)이나 라즈베리 파이 같은 arm64 리눅스에서 JetDeck을 직접 실행할 수 있어요. 받아서 `chmod +x JetDeck-*-arm64.AppImage && ./JetDeck-*-arm64.AppImage`.
- arm64판도 새 버전이 나오면 앱이 알아서 받아 두고 알려 줘요 (arm64 전용 업데이트 정보를 따로 써요).
- 실제 Jetson Orin Nano(Ubuntu 24.04)에서 앱이 켜지고 화면이 뜨는 것까지 확인했어요. (모니터 없는 상태에서 화면 출력 없이 확인했고, 직접 화면에 띄워 쓰는 것까지는 해 보지 못했어요.)

> PC에서 젯슨에 접속하는 용도라면 지금처럼 Windows·x64 Linux판을 쓰면 돼요. arm64판은 **젯슨 같은 기기 자체에서** JetDeck을 실행할 때 필요해요.

## ⬇ 내려받기

| 파일 | 용도 |
|---|---|
| `JetDeck-Setup-2.2.1.exe` | **Windows 설치판 (추천)** — 자동 업데이트 |
| `JetDeck-2.2.1-portable.exe` | Windows 설치 없이 실행 |
| `JetDeck-2.2.1-x86_64.AppImage` | Linux x64 (자동 업데이트) |
| `JetDeck-2.2.1-arm64.AppImage` | Linux arm64 — Jetson 등 (자동 업데이트) |

2.2의 새 기능(분할 화면 · 일반 리눅스 모니터 · SSH 키 마법사)은 [2.2.0 릴리스 노트](v2.2.0.md)를 참고해 주세요.
