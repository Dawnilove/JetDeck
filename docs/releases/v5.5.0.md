# JetDeck 5.5.0

> **플러그인 모음** 업데이트예요. **플러그인 관리 → 모음** 탭에서 관리자가 명령을 읽어 본 팩을 서명된 목록으로 보고, 앱 안에서 바로 설치할 수 있어요. 설치한 팩도 허용 창에서 명령을 읽고 허용해야 켜져요. 기기에는 아무것도 설치하지 않아요.

5.4.0을 쓰고 있다면 앱을 켤 때 **자동으로 받아서** 화면 위쪽에 알려 줘요. **다시 시작해서 업데이트**를 누르면 끝.

## ✨ 새 기능

- **모음 탭** — 플러그인 관리 창 위쪽에 **[내 팩] [모음]** 탭이 생겼어요. 목록에서 팩 이름·버전·제출자·항목 수·태그를 보고, 검색(내 PC에서만 찾아요)과 "읽기만" 필터를 쓸 수 있어요.
- **처음 열 때 안내** — 어떤 정보를 보내고 보내지 않는지 먼저 알려 주고, **계속**을 눌러야 접속해요. 앱을 켤 때는 아무것도 받지 않아요.
- **내용 보기 → 설치** — **내용 보기**를 누르면 팩 파일을 받아 지문을 확인한 뒤, 기존 허용 창에 **출처 구역**(JetDeck 모음 · 검토됨, 제출자, 검토 날짜, 서명·지문 확인, 이미 설치된 버전과 바뀐 명령)을 더해 보여 줘요. **설치만 (꺼진 채)** 또는 **허용하고 켜기**를 골라요.
- **출처 칩** — "내가 설치한 팩"에 `공식` · `모음` · `직접 설치` 칩이 붙어요.
- **상태 안내** — 오프라인(마지막으로 받은 목록 표시), 목록 서명이 맞지 않음, 옛 목록, 목록 만료(새 설치 막힘), 앱 버전이 낮음, 철회됨, 안전 모드(목록은 보이고 설치만 막힘)를 모음 탭 안에서 쉬운 말로 알려요. 문제가 있어도 앱의 다른 기능에는 퍼지지 않아요.
- **첫 공개 팩 3개** — "USB·카메라 점검", "네트워크 점검", "저장 공간 점검". 모두 읽기 전용 항목 5개씩이에요.
- **업데이트 내용 창** — 항목을 버전당 한 줄 4~5개로 줄이고 **자세히 보기** 링크(이 릴리스 노트)를 더했어요.
- **관리자용 문서** — [docs/plugins/publish.md](https://github.com/Dawnilove/JetDeck/blob/main/docs/plugins/publish.md)에 목록 만들기·서명·확인·철회·열쇠 분실/유출 절차를 적었어요. 보안 문서에 모음 절과 `docs/packs/index.schema.json`도 더했어요.

## ⚠ 바뀐 점 — 꼭 읽어 주세요

- **"검토됨"은 안전 보증이 아니에요.** 관리자가 명령을 읽어 봤다는 뜻이에요. 모음에서 받은 팩도 허용 창에서 명령 전문을 읽고 허용해야 켜지고, 파일이 바뀌면 다시 허용해야 해요.
- **모음 탭을 열고 동의하면** 내 IP 주소·접속 시각·앱 이름과 버전이 서버에 보여요(요청 자체). 기기 정보, 설치한 팩 목록, 검색어, 사용 기록은 보내지 않아요. 동의는 모음 탭 아래쪽 **모음 동의 끄기**로 끌 수 있어요.
- **목록은 서명돼요.** 앱에 들어 있는 공개 열쇠로 서명을 먼저 확인하고, 틀리면 목록을 보여 주지 않아요. 목록은 만든 날부터 4년 뒤 만료되고, 만료되면 목록은 보이지만 새 설치가 막혀요.
- **철회된 팩**은 설치할 수 없고, 이미 설치했다면 "내가 설치한 팩"에 이유와 함께 빨간 줄로 알려요. **자동으로 끄는 것은 아직 없어요**(5.6.0 예정) — 직접 끄거나 제거해 주세요.
- **팩 제출 절차는 아직 없어요.** 지금은 관리자가 올린 팩만 있어요(제출 양식과 검사는 5.6.0 예정).
- 5.4.0 이하 앱에는 모음 탭이 없어요.

## 확인한 범위

확인한 것:

- 자동 시험 396개, 타입 검사, 영어 사전 검사(누락 0), 빌드 통과. 서명·지문·rollback·만료·철회·리다이렉트·크기 한도 같은 위협 사례를 네트워크 없이 시험으로 고정했어요.
- 실제 앱(빌드본)을 **로컬 가짜 서버**로 움직여 확인: 안내 → 목록 → 내용 보기 → 설치만 / 허용하고 켜기 → 켜짐, 업데이트 있음, 철회(목록과 설치본), 만료, 서명 변조, 옛 목록, 서버 끊김(오프라인 목록), 빈 목록, 앱 버전 낮음, `--safe-mode`(설치 막힘), 영어 화면, 밝은 테마의 설치 확인 창.
- **실제 공개 서버(GitHub Pages)** 에서 목록과 팩 파일이 열리고 받은 파일의 지문이 저장소와 같은 것, 새 앱(새 userData)에서 목록 표시 → 내용 보기 → 허용하고 켜기까지 확인했어요(개발 빌드 기준, 설치판은 아직).
- 게시 도구 `gallery:build`가 첫 공개 팩 3개를 앱 검증기로 검사해 통과했어요(서명은 관리자가 따로 해요).

**확인하지 못한 것**:

- 첫 공개 팩 3개의 명령을 **실제 Jetson에서 실행**해 보지는 않았어요(앱 검증기의 읽기 전용 판정만 확인).
- 밝은 테마의 목록 화면과 상태 줄 색, 영어 상태 줄의 눈 확인(문구는 확인), 키보드·화면 낭독기 사용, 받는 중 취소 버튼, 설치판 업데이트 알림.
- 회사망·프록시가 막는 환경, 느린 연결에서의 15초 제한.
