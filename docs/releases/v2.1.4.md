# JetDeck 2.1.4

> Claude Desktop(Microsoft Store판)에서 "JetDeck을 켜지 못했어요"라며 연결되지 않던 진짜 원인을 고쳤어요.

2.1.3 이하를 쓰고 있다면 앱을 켤 때 **자동으로 받아서** 화면 위쪽에 알려 줘요. **다시 시작해서 업데이트**를 누르면 끝.

## 🛠 고친 점

- **Claude에서 JetDeck을 못 찾던 문제** — Microsoft Store로 설치한 Claude Desktop 안에서 도는 프로그램은 Windows가 `%APPDATA%` 폴더를 **가짜 복사본**으로 보여 줘요. JetDeck이 AI에게 알려 주는 연결 정보 파일(`mcp.json`)이 거기 있어서, AI는 JetDeck이 이미 켜져 있어도 예전 값만 읽고 `JetDeck을 켜지 못했어요`라고 했어요. 이제 연결 정보를 가짜 복사본이 없는 **홈 폴더(`~/.jetdeck`)** 에 적어서 항상 최신 값을 읽어요.
- **AI가 JetDeck을 켜는 방식** — 연결 프로그램이 JetDeck을 직접 켜면 같은 가짜 복사본 안에서 켜져 저장 데이터가 갈라질 수 있어서, 이제 탐색기를 통해 따로 켜요.

> **참고** 이 업데이트를 설치하고 나면, Claude 쪽에서 JetDeck 도구가 한 번 끊겼다가 새로 연결돼야 해요. Claude Code는 `/mcp`로 다시 연결하고, Claude Desktop·Cursor 등은 그 프로그램을 다시 켜 주세요.

## ⬇ 내려받기

| 파일 | 용도 |
|---|---|
| `JetDeck-Setup-2.1.4.exe` | **Windows 설치판 (추천)** — 자동 업데이트 |
| `JetDeck-2.1.4-portable.exe` | Windows 설치 없이 실행 |
| `JetDeck-2.1.4-x86_64.AppImage` | Linux x64 (자동 업데이트) |

MCP 연결 기능 설명은 [2.1.0 릴리스 노트](https://github.com/Dawnilove/JetDeck/blob/main/docs/releases/v2.1.0.md)를 참고해 주세요.
