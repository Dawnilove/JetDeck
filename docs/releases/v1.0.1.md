# JetDeck 1.0.1

1.0.0을 설치했다면 앱을 켤 때 **자동으로 받아서** 화면 위쪽에 알려 줘요.
**다시 시작해서 업데이트**를 누르거나, 그냥 두면 다음에 앱을 끌 때 설치돼요.

## 새 기능: Claude에 연결 (MCP)

Claude Desktop·Claude Code가 JetDeck에 저장된 젯슨을 직접 다룰 수 있어요.
"젯슨 온도 확인해 줘", "~/ros2_ws 빌드하고 오류 고쳐 줘" 같은 요청을 Claude가 젯슨에서 바로 실행해요.

- 연결 관리 화면 위쪽 **Claude 연결** 버튼 → 설정을 복사해 Claude에 붙여 넣기
- Claude가 쓸 수 있는 도구: 호스트 목록, 연결, 명령 실행, 파일 읽기·쓰기, 폴더 목록, 시스템 상태
- **rm·sudo·reboot·kill·dd·apt 같은 위험한 명령**과 `>`로 파일을 덮어쓰는 명령은 JetDeck 화면에 확인 창이 떠요. **허용**을 눌러야 실행되고, 2분 안에 답이 없으면 거부돼요
- JetDeck이 꺼져 있으면 Claude가 처음 도구를 쓸 때 자동으로 켜져요
- JetDeck은 내 PC 안(127.0.0.1)에서만, 비밀 토큰이 있는 요청만 받아요

## 바뀐 점

- 연결 관리 화면 왼쪽 위에 **앱 버전**(`v1.0.1`)을 표시해요. 버그를 알려 주실 때 이 버전을 적어 주세요
- 비밀번호 로그인을 막아 둔(SSH 키만 허용) 기기에 비밀번호로 접속하면 "인증 실패" 대신 **"이 기기는 비밀번호 로그인을 막아 두었어요"**라고 정확히 알려 줘요
- keyboard-interactive 방식만 켜 둔 서버에도 비밀번호로 접속할 수 있어요
- JetDeck을 두 번 실행하면 창을 새로 띄우지 않고 기존 창을 앞으로 가져와요
- 설치 파일 크기를 크게 줄였어요 (화면에서만 쓰는 라이브러리를 중복으로 넣지 않음)

## 내려받기

| 파일 | 용도 |
|---|---|
| `JetDeck-Setup-1.0.1.exe` | 설치판 (추천, 자동 업데이트) |
| `JetDeck-1.0.1-portable.exe` | 설치 없이 실행 (자동 업데이트 없음) |

전체 기능과 알려진 제한은 [1.0.0 릴리스 노트](v1.0.0.md)를 참고해 주세요.
