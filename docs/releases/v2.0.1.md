# JetDeck 2.0.1

> 터미널 굵은 글씨가 어긋나 보이던 문제를 고쳤어요.

2.0.0을 쓰고 있다면 앱을 켤 때 **자동으로 받아서** 화면 위쪽에 알려 줘요. **다시 시작해서 업데이트**를 누르면 끝.

## 🛠 고친 점

- **터미널 굵은 글씨 간격** — 젯슨에 처음 연결했을 때 프롬프트(`user@jetson:~$`) 같은 굵은 글씨가 `j asonnano@ ason…`처럼 벌어지거나 겹쳐 보이던 문제.
  굵은 글꼴 파일이 늦게 불러와지는 동안 터미널이 다른 글꼴로 글자 폭을 재서 생겼어요. 이제 앱을 켤 때 터미널 글꼴을 먼저 불러와요 (테마를 바꾸면 풀리던 증상).

## ⬇ 내려받기

| 파일 | 용도 |
|---|---|
| `JetDeck-Setup-2.0.1.exe` | **Windows 설치판 (추천)** — 자동 업데이트 |
| `JetDeck-2.0.1-portable.exe` | Windows 설치 없이 실행 |
| `JetDeck-2.0.1-x86_64.AppImage` | Linux x64 (자동 업데이트) |

2.0의 새 기능(ROS2 도구 · 시리얼 콘솔 · Linux · 테마 17종)은 [2.0.0 릴리스 노트](v2.0.0.md)를 참고해 주세요.
