# JetDeck 6.1.2

> **보안 후속 수정**이에요. 6.0.0 보안 리뷰의 낮음 항목 중 아직 남아 있던 3건을 고쳤어요. 새 기능은 없어요.

5.x·6.x를 쓰고 있다면 앱을 켤 때 **자동으로 받아서** 알려 줘요. **다시 시작해서 업데이트**를 누르면 끝.

## 고친 것

- **읽기 root 제한 강화** — 팩이 읽기 root로 `~/.config`·`~/.cache`·`~/.local` 폴더 전체를 선언하면 이제 거부해요. 읽기 거부 목록에 `.envrc`·`fish_history`·`.git/config`도 더했어요. `~/.ros/log`나 `~/.config/앱이름`처럼 하위 폴더는 그대로 쓸 수 있어요.
- **화면 속임 글자 추가 차단** — 줄 구분(U+2028·U+2029), 소프트 하이픈(U+00AD), 몽골 모음 구분(U+180E), 주석 표시(U+FFF9~U+FFFB)를 경로·필드 값에서 거부하고, 표시 이름에서는 지워요. 확인 창에 나오는 Device 경로(`remotePath`)도 같은 정리를 거쳐요.
- **닫힌 소켓의 터널 채널 정리** — 접속한 프로그램이 SSH 채널이 열리기 전에 끊으면 Device 쪽 채널이 연결이 끝날 때까지 남을 수 있었어요. 이제 바로 닫아요. 포워딩 규칙(L·D)·팩 터널·원격 포워딩이 모두 같은 코드를 써요.

## 확인한 범위

확인한 것: 자동 시험 560개, 타입 검사 통과. 위 3건은 시험으로 고정했어요.

**확인하지 못한 것**:

- 실제 Device·Electron 화면에서의 동작. 시험은 순수 함수와 가짜 소켓으로 했어요.
- 닫힘 레이스를 실제 SSH 연결에서 일으켜 보지 않았어요.
- 읽기 목록 크기 상한(`list`의 `readdir`)은 이번 범위가 아니에요.
