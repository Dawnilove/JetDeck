# JetDeck 2.1.2

> 시스템 모니터가 더 부드러워지고, ROS2 launch 탭이 파일을 못 찾던 문제와 AI가 "JetDeck을 켜지 못했어요"라며 연결하지 못하던 문제를 고쳤어요.

2.1.1 이하를 쓰고 있다면 앱을 켤 때 **자동으로 받아서** 화면 위쪽에 알려 줘요. **다시 시작해서 업데이트**를 누르면 끝.

## ✨ 개선

- **시스템 모니터가 더 부드러워졌어요** — 읽는 간격을 1초에서 **0.5초**로 줄이고, 막대가 다음 값까지 멈추지 않고 일정하게 움직이도록 바꿨어요. 이전에는 0.4초만 움직이고 멈춰서 계단처럼 끊겨 보였어요. 젯슨의 `tegrastats` 부하는 늘지 않아요(측정: 둘 다 0.1% 안팎).

## 🛠 고친 점

- **ROS2 launch 탭이 비어 있던 문제** — 설치된 패키지(`demo_nodes_cpp` 등)의 launch 파일이 "launch 파일이 없어요"로 나오던 문제. `foo.launch.py`만 찾고 `foo_launch.py`(ROS2 패키지에서 더 흔한 이름)와 `.yaml`은 못 찾았어요. 이제 둘 다 찾고, 실제 젯슨(ROS2 Jazzy)에서 목록을 확인하고 `ros2 launch`가 새 터미널 탭에서 실행되는 것까지 확인했어요.
- **AI가 JetDeck을 못 찾던 문제** — JetDeck이 켜져 있는데도 Claude 같은 AI가 `JetDeck을 켜지 못했어요`라고 하며 연결하지 못하던 경우가 있었어요. AI가 JetDeck을 찾는 데 쓰는 연결 정보 파일(`mcp.json`)이 예전 값으로 남아 있던 게 원인이에요.
  이제 JetDeck이 5초마다 이 파일을 확인해 다르면 다시 써서, 한 번 잘못돼도 스스로 복구돼요. (이 문제는 직접 재현하지는 못해서, 같은 일이 또 생기면 알려 주세요.)

## ⬇ 내려받기

| 파일 | 용도 |
|---|---|
| `JetDeck-Setup-2.1.2.exe` | **Windows 설치판 (추천)** — 자동 업데이트 |
| `JetDeck-2.1.2-portable.exe` | Windows 설치 없이 실행 |
| `JetDeck-2.1.2-x86_64.AppImage` | Linux x64 (자동 업데이트) |

MCP 연결 기능 설명은 [2.1.0 릴리스 노트](https://github.com/Dawnilove/JetDeck/blob/main/docs/releases/v2.1.0.md)를 참고해 주세요.
