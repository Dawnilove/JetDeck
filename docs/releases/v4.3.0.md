# JetDeck 4.3.0

> 4.0.1 이후 **개발 작업, 기기 관리, 설정 백업, AI 터미널 읽기**가 들어왔어요(4.1.0 · 4.2.0 · 4.3.0을 한 번에 출시). 기기에는 여전히 아무것도 설치하지 않고 SSH로만 동작해요.

4.0.1 이하를 쓰고 있다면 앱을 켤 때 **자동으로 받아서** 화면 위쪽에 알려 줘요. **다시 시작해서 업데이트**를 누르면 끝.

## ✨ 새 기능

### 개발 작업 흐름 (4.1)
- **시작 화면** — 빈 편집기 자리에 최근 연 파일과 자주 쓰는 도구 버튼이 나와요.
- **빌드 도구** — 기기에서 `colcon build`·`catkin_make`를 실행하고 출력을 실시간으로 봐요. 오류·경고 줄을 누르면 그 파일·줄로 이동해요. `rosdep install`은 sudo 비밀번호가 필요할 수 있어 새 터미널 탭에서 실행해요.
- **파일 검색·바꾸기** (`Ctrl+Shift+F`) — 기기 폴더 안의 글자를 찾고(결과를 누르면 그 줄로 열기), 한 번에 바꿔요. 바꾸기는 파일이 그 사이 바뀌었는지 확인한 뒤 안전하게 저장해요.
- **Git 상태** — 탐색기에 브랜치와 바뀐 파일·폴더(M/A/D/U)가 표시돼요.

### 기기 관리 (4.2)
- **서비스 (systemd)** — 서비스 목록과 상태, **시작·정지·재시작**, `journalctl` 로그(마지막 200줄 또는 **실시간**). "실패한 것만" 필터가 있어요. sudo 비밀번호가 필요하면 JetDeck이 비밀번호를 받지 않고 **새 터미널 탭**에서 직접 입력하게 해요. SSH 서버를 멈추면 연결이 끊긴다고 미리 알려 줘요.
- **기기 점검** — 온도, Wi-Fi 신호, 디스크 SMART, 실패한 서비스를 읽기만 해요. 연결된 동안 1분마다 확인하고, **80℃ 이상 · 실패한 서비스 · 디스크 이상**이 새로 생기면 알림을 보내요. SMART는 기기에 `smartctl`이 이미 있을 때만 볼 수 있어요(JetDeck은 설치하지 않아요).

### 데이터·AI (4.3)
- **설정 내보내기·가져오기** — 연결 관리 화면 위쪽 버튼으로 호스트 목록·스니펫·테마를 파일 하나로 옮겨요. **비밀번호는 들어가지 않고**(키 파일은 경로만), 스니펫 안의 비밀처럼 보이는 값은 가려요. 가져올 때 이미 있는 기기는 건너뛰어요. 비밀번호 방식 호스트는 가져온 뒤 비밀번호를 다시 입력해 주세요.
- **AI가 터미널 읽기** — Claude·Cursor 같은 AI가 열려 있는 **터미널 탭의 최근 출력**을 읽을 수 있어요(MCP `read_terminal`). 처음 읽을 때 JetDeck이 **허용 여부를 물어요**(AI 도구·기기별, 앱을 닫을 때까지 유지). 비밀번호·토큰처럼 보이는 값은 가려서 보내고, AI 활동 기록에는 터미널 내용을 남기지 않아요. 앱 화면 전체를 읽지는 않아요.
- **비밀 가리기 보강** — `API_TOKEN=…`처럼 이름 앞에 글자가 붙은 값도 가려요.

## ⚠ 알아 두세요 (미확인)
- 서비스 시작·정지의 실제 성공(sudo 비밀번호 필요), 알림 팝업, Wi-Fi 신호·SMART 실제 값(시험한 젯슨은 유선이고 `smartctl`이 없었어요), 설정 저장·열기 창의 흐름, 영어 화면은 직접 확인하지 못했어요. 문제가 있으면 [이슈](https://github.com/Dawnilove/JetDeck/issues)로 알려 주세요.
- 비밀 가리기는 패턴으로 찾기 때문에 **모든 비밀을 막지는 못해요**. 터미널에 중요한 값을 띄운 채로 AI에 읽기를 허용하지 마세요.
- `vim`·`htop` 같은 전체 화면 프로그램의 출력은 AI가 읽기 어려울 수 있어요.
