# JetDeck 1.0.0

첫 정식 버전이에요. Jetson에 SSH로 접속해 터미널·파일 편집·모니터·파일 전송·포트 포워딩을 한 창에서 할 수 있어요.

## 내려받기

| 파일 | 용도 |
|---|---|
| `JetDeck-Setup-1.0.0.exe` | 설치판 (추천). 시작 메뉴·바탕화면 바로가기, 자동 업데이트 |
| `JetDeck-1.0.0-portable.exe` | 설치 없이 실행. 자동 업데이트 없음 |

> 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**. 코드 서명 인증서가 아직 없어서 생기는 안내예요.

## 기능

- **연결 관리**: 호스트 저장, 비밀번호 또는 SSH 키(ssh-agent 지원), 온라인 표시, 연결 테스트
- **주변 Jetson 찾기**: 같은 네트워크(/24)와 USB 연결(192.168.55.1)에서 SSH 기기 검색. NVIDIA 유선 MAC이면 표시
- **호스트 키 확인**: 처음 접속 때 지문 확인, 키가 바뀌거나 종류가 달라지면 경고, `@revoked` 키 거부
- **터미널**: 여러 탭, 화면 분할, 터미널만 크게, 빠른 명령 버튼(위험한 명령은 실행 전 확인)
- **원격 편집기**: 탐색기에서 열어 편집, `Ctrl+S` 저장, 원격에서 바뀐 파일 덮어쓰기 전 확인, 원자적 저장
- **탐색기**: 새 파일·폴더, 이름 바꾸기, 삭제, 우클릭 업로드·다운로드, 키보드 이동
- **시스템 모니터**: CPU 코어별, GPU, 메모리, 저장공간, 온도, 소비 전력, ROS·Python 버전
- **전원**: 전원 모드 전환, 재부팅·종료·절전, Wake-on-LAN 깨우기
- **파일 전송**: 양쪽 목록, 끌어다 놓기, 덮어쓰기 확인, 진행률·속도, 전송 취소
- **포트 포워딩**: 로컬·원격·동적(SOCKS5), 호스트별 저장, 접속하면 자동 시작
- **자동 재연결**: 끊기면 2→4→8…30초 간격으로 최대 10번, 열어 둔 터미널 탭 유지
- **테마 4종**: 기본 다크(라임), 라이트(올리브), 모노 다크, 솜사탕(파스텔). 사용자 테마 JSON 추가 가능
- **자동 업데이트 알림**: 새 버전을 받아 두고 "다시 시작해서 업데이트"

## 보안

- 비밀번호는 Windows DPAPI로 암호화해 이 PC에만 저장, 저장할 때와 같은 서버·계정에만 사용
- 창 이동·새로고침 차단, 외부 링크는 http/https만 기본 브라우저로, 렌더러 샌드박스
- 네트워크 경로(`\\서버\공유`)의 키 파일 거부, 원격 경로의 제어문자 거부

## 알려진 제한

- X11 포워딩은 지원하지 않아요 (다음 버전 검토)
- 폴더 통째 전송은 아직 안 돼요 (파일만)
- 5MB 초과·바이너리·UTF-8이 아닌 파일은 편집기로 열지 않아요
- 암호 걸린 키는 앱에서 직접 입력할 수 없어요 → `ssh-add`로 ssh-agent에 등록
- 주변 기기 검색은 PC가 붙은 네트워크의 같은 /24 대역만 찾아요
