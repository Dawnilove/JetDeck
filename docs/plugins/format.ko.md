# 팩 형식 (`format: 1`)

> 영어 문서([format.md](format.md))가 기준이에요. 이 문서는 번역이에요. [목차로](README.md)

**팩**은 `*.jdpack.json` 파일 하나예요. 팩 안에 **플러그인**이, 플러그인 안에 **항목(action)**이 있어요. JetDeck은 항목의 명령을 Device(젯슨)에서 실행하고 결과를 글자나 표로 보여 줘요. 내 PC에서 실행되는 코드는 팩에 없어요.

파일 첫 줄에 `"$schema": "https://dawnilove.github.io/JetDeck/plugins/jdpack.schema.json"` 을 쓰면 VS Code에서 자동 완성과 오류 표시가 돼요. 모르는 필드는 무시해요(`$comment`는 써도 돼요).

## 팩

| 필드 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `id` | 글자 | ○ | 소문자·숫자·`-`, 글자로 시작, 40자 이내. 예약어: `device ros2 ros2-live monitor perf devtools examples jetdeck official app core snippets`, `jetdeck-`로 시작하는 이름 |
| `format` | `1` | ○ | 5.x에서는 항상 `1` |
| `version` | 글자 | ○ | `1.2.3` 형식 (`-접미사` 가능) |
| `name` | 글자쌍 | ○ | 60자 이내 |
| `desc` | 글자쌍 | | 300자 이내 |
| `author`, `license`, `homepage` | 글자 | | 표시만 해요. `homepage`를 앱이 열지는 않아요 |
| `minApp` | 글자 | | 필요한 최소 JetDeck 버전. 더 낮은 앱은 팩을 거부해요 |
| `plugins` | 배열 | ○ | 최대 20개. 팩에 `badges`가 있으면 빈 `[]`도 돼요 |
| `badges` | 배열 | | [탐색기 배지](#탐색기-배지-530). 최대 2개(공식 4개). `minApp` 5.3.0 필요 |

**글자쌍**은 그냥 글자이거나 `{ "ko": "…", "en": "…" }` 예요. 한쪽이 없으면 다른 쪽을 써요.

## 플러그인

| 필드 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `id` | 글자 | ○ | 팩 안에서 유일 |
| `title` | 글자쌍 | ○ | 탭 이름. 60자 이내 |
| `desc` | 글자쌍 | | 300자 이내 |
| `icon` | 글자 | | 예약. 소문자 단어 |
| `actions` | 배열 | ○ | 플러그인당 50개, 팩당 200개 |

외부 팩은 활동 막대의 **플러그인** 버튼 아래에 나타나요. (기존 묶음에 들어가는 건 앱에 동봉된 팩만 돼요.)

## 항목 (action)

| 필드 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `id` | 글자 | ○ | 플러그인 안에서 유일 |
| `label` | 글자쌍 | ○ | 버튼 이름. 60자 이내 |
| `desc` | 글자쌍 | | 300자 이내 |
| `cmd` | 글자 | ○ | 2000자 이내, 제어 문자 금지. `{이름}`은 `params`의 선택지로 바뀌어요. `sudo`는 쓰지 말고 `"sudo": true`를 써요 |
| `risk` | `read` · `change` · `danger` | ○ | 내가 적는 위험도. [위험도](#위험도) 참고 |
| `mode` | `exec` · `terminal` · `stream` | | `exec`(기본)는 실행하고 결과를 보여 줘요. `terminal`은 열린 터미널에 `cmd`를 입력해 줘요(최대 20줄). `stream`은 끝나지 않는 출력을 실시간으로 보여 줘요([아래](#흐르는-출력과-입력-폼-510)) |
| `enter` | true/false | | `terminal` 전용. 기본 `true` = 입력 뒤 Enter |
| `sudo` | true/false | | `exec` 전용. 앱이 `sudo`를 붙여요. 파이프·리다이렉트 없는 단일 명령만. `read`와 같이 못 써요 |
| `confirm` | 글자쌍 | 바꿈·위험 | 확인창에 보여 줄 설명. 500자 이내 |
| `preview` | 글자 | 정리·설치류 | 실제 실행 전에 보여 줄 읽기 전용 명령. 삭제·설치·정리 항목은 필수 |
| `fields` | 배열 | | 입력 폼(5.1.0, [아래](#흐르는-출력과-입력-폼-510)). `params`와 같이 쓸 수 없어요 |
| `params` | 배열 | | 선택지 `[{ "name", "label", "choices": [{ "value", "label" }] }]`. 선택지는 30개까지. `value`에는 셸 특수문자가 없고 `-`로 시작하지 않아요 |
| `auto` | true/false | | 화면을 열면 바로 실행. 앱이 계산한 위험도가 `read`일 때만. 팩당 5개 |
| `display` | 객체 | | `{ "type": "text" }`, 아래 표, `stream`용 `{ "type": "log" }`, 또는 `{ "type": "chart" }`([5.2.0](#그래프-520)) |
| `timeout` | 숫자 | | 초. 기본 60, 외부 팩은 최대 600. `stream`은 최대 실행 시간(기본 600, 최대 3600) |
| `stopGrace` | 숫자 | | `stream` 전용([5.4.0](#정지-유예-stopgrace-540)). Ctrl-C를 보낸 뒤 채널을 닫기까지 기다리는 초. 기본 3, 외부 팩은 3~10 |
| `disconnects` | true/false | | 실행하면 연결이 끊김(재부팅·종료) |
| `shell` | `sh` · `bash-i` | | `bash-i`는 `~/.bashrc`를 불러와요(ROS2 등) |
| `when` | `jetson` | | 젯슨일 때만 보여요 |

검사를 통과하지 못한 항목은 빠지고, 이유는 플러그인 관리 창에 나와요. 이 앱 버전이 모르는 값(더 새로운 `mode`·`display.type`)이 있는 항목은 "새 버전 앱이 필요해요" 안내와 함께 숨겨져요.

### 표 표시

```json
"display": {
  "type": "table",
  "match": "^(\\S+)\\s+(\\S+)$",
  "columns": [ "이름", "값" ],
  "skip": 1,
  "empty": "찾은 게 없어요."
}
```

| 필드 | 설명 |
|---|---|
| `columns` | 열 제목(글자쌍). 20개까지 |
| `match` | 정규식. 출력의 한 줄마다 적용하고 괄호 묶음이 열이 돼요. 맞지 않는 줄은 무시해요 |
| `split` | `match` 대신: `ws`(공백으로 나눔) 또는 `tab` |
| `skip` | 앞의 몇 줄을 건너뜀 |
| `empty` | 행이 없을 때 보여 줄 글자 |
| `labels` | 첫 열 값 → 읽기 쉬운 이름 |

`match`는 200자 이내, `(a+)+` 같은 중첩 수량자·역참조·lookbehind를 쓸 수 없어요. 표는 500행, 한 줄 1000자까지 보여요.

## 흐르는 출력과 입력 폼 (5.1.0)

이 절의 기능을 쓰는 팩에는 `"minApp": "5.1.0"`을 적으세요. 더 오래된 앱은 "JetDeck 5.1.0 이상이 필요해요"라며 팩 전체를 거부해요.

### 흐르는 출력: `mode: "stream"`

`stream` 항목은 스스로 끝나지 않는 명령(`journalctl -f`, `ros2 topic echo`)을 시작하고, 나오는 줄을 바로 보여 줘요. `"display": { "type": "log", "maxLines": 1000 }`을 써요. `maxLines`는 화면에 남기는 줄 수예요(100~5000, 기본 1000).

* 사용자가 **시작**과 **멈춤**을 눌러요. 스트림은 스스로 시작하지 않아서 `auto`는 쓸 수 없어요.
* **화면을 나가거나 연결을 끊거나 앱을 닫으면** Device의 명령도 끝나요. 앱이 Ctrl-C를 보내고, 3초(또는 `stopGrace`) 뒤 채널을 닫고, `timeout`이 끝나도 멈춰요.
* `timeout`은 최대 실행 시간이에요. 기본 600, 외부 팩은 최대 3600.
* 스트림에 쓸 수 없는 것: `sudo`, `preview`, `auto`, 삭제·설치·디스크 명령.
* 한도: 팩당 동시 2개, 앱 전체 4개. 출력이 초당 1MB(5초 평균)를 넘거나 20MB를 넘으면 스스로 멈춰요.
* 스트림에서 **읽기**로 인정하는 끝나지 않는 명령은 짧은 목록뿐이에요: `journalctl -f`, `tail -f`/`-F`, `dmesg -w`, `top -b`, `iostat`, `mpstat`, `tegrastats`, `ros2 topic echo|hz|bw|delay`(안전한 옵션만, `--filter` 불가), `ip monitor`, `udevadm monitor`. 그 밖의 스트림(`ros2 launch`, `colcon build` …)은 읽기가 아니라서 먼저 물어요.

### 정지 유예: `stopGrace` (5.4.0)

사용자가 스트림을 멈추면 앱은 먼저 Ctrl-C를 보내고, 기다린 뒤 채널을 닫아요(이때 SIGHUP이 가요). 기다리는 시간은 3초예요. 노드가 많은 `ros2 launch`처럼 정리에 더 걸리는 프로그램은 더 길게 요청할 수 있어요.

```json
{ "id": "launch-file", "mode": "stream", "cmd": "ros2 launch {file}", "risk": "change",
  "confirm": { "ko": "launch 파일은 이 기기에서 프로그램을 실행해요." },
  "shell": "bash-i", "stopGrace": 10, "fields": [ ... ] }
```

* `stopGrace`는 초 단위이고 `stream` 항목에만 쓸 수 있어요. 외부 팩은 3~10, 공식 팩은 3~30이에요.
* 채널을 닫는 시점만 바꿔요. 화면을 나가거나 연결이 끊기거나 앱을 닫을 때의 정리는 그대로예요. 앱을 닫을 때는 기다리지 않아요.
* 팩에 `"minApp": "5.4.0"`을 적으세요. 더 오래된 앱은 이 필드를 무시하고 3초만 기다려요.
* 기본 꺼짐인 공식 팩 `ros2-live`가 예시예요: `find`로 읽은 파일 목록을 쓰는 `ros2 launch {file}`, 속도 선택과 반복 체크가 있는 `ros2 bag play`. 둘 다 먼저 물어요.

### 입력 폼: `fields`

`fields`(최대 6개)로 사용자가 값을 고르거나 적게 해요. 각 `name`이 `cmd`의 `{name}` 자리를 채워요. `fields`와 `params`는 **둘 중 하나**만 써요.

| `type` | 추가 필드 | 받는 값 | 명령에 들어가는 모양 |
|---|---|---|---|
| `select` | `choices`(고정, `params`와 같음) **또는** `from` | `choices`: 적힌 값만. `from`: 영문·숫자·`_ . @ : ~ / + -`, 100자 이내 | 고정: 적힌 그대로. `from`: 따옴표 처리한 단어 하나 |
| `text` | `charset`(`word` 기본, `ros`, `free`), `maxLen`(≤200, 기본 60) | `word` = `A-Za-z0-9_.-`, `ros` = `A-Za-z0-9_/~`, `free` = 줄바꿈·제어 문자 없는 모든 글자 | 따옴표 처리한 단어 하나 |
| `int` | `min`(≥0), `max`(≤1000000) | 숫자만, 음수 불가 | 숫자 |
| `path` | `maxLen`(≤300) | `/`로 시작하는 절대 경로, `..` 불가 | 따옴표 처리한 단어 하나 |
| `flag` | `on`(체크했을 때 들어갈 글자, `A-Za-z0-9_.=-`) | 사용자는 체크 여부만 정함 | `on` 또는 빈 글자 |

공통 필드: `name`, `label`(글자쌍), `type`, `desc`, `default`(항상 **글자**, 예: `"50"`. `flag`는 true/false), `required`(기본 `true`).

앱이 지키게 하는 규칙(어기면 그 항목이 빠져요):

* 값은 `-`로 시작할 수 없고, 줄바꿈·제어 문자도 없어요.
* 자리는 맨 단어로 써요: `journalctl -u {unit} -n {lines}`. 따옴표 안(`'{unit}'`), 명령 이름 자리, `$( )`·백틱·`sh -c` 안, 리다이렉트 대상에는 쓸 수 없어요.
* 값 앞에 `--`가 필요한 명령이면 직접 적어요: `grep -- {pattern} file`.
* `sudo` 항목에는 고정 `select`·`int`·`flag`만 쓸 수 있어요.
* **앱은 실행할 때마다 값을 채운 명령을 다시 분석해요.** 값 때문에 위험해지면(`~/.ssh/id_rsa` 같은 경로) 먼저 물어보고 "입력한 값 때문에 위험도가 올라갔어요"라고 알려 줘요.

#### `from`: 기기에서 불러오는 선택지

```json
{ "name": "topic", "label": "토픽", "type": "select",
  "from": { "cmd": "ros2 topic list", "shell": "bash-i", "timeout": 15, "charset": "ros", "max": 200 } }
```

명령은 읽기 전용이어야 하고, 아니면 항목이 거부돼요. 카드를 열 때와 **새로고침**을 누를 때 **스스로** 실행돼서 팩당 자동 실행 5개 한도에 들어가요. 출력 한 줄이 선택지 하나예요. `charset`(`word`·`ros`·`path`)에 맞지 않는 줄은 버려요. 최대 200개.

### 예

```json
{
  "format": 1, "id": "my-logs", "version": "1.0.0", "minApp": "5.1.0",
  "name": "내 로그",
  "plugins": [{
    "id": "logs", "title": "로그",
    "actions": [{
      "id": "follow", "label": "서비스 로그 따라 보기",
      "mode": "stream", "risk": "read",
      "cmd": "journalctl --no-pager -u {unit} -n {lines} -f",
      "fields": [
        { "name": "unit", "label": "서비스", "type": "select",
          "choices": [ { "value": "ssh", "label": "ssh" }, { "value": "docker", "label": "docker" } ] },
        { "name": "lines", "label": "처음 줄 수", "type": "int", "min": 10, "max": 500, "default": "50" }
      ],
      "timeout": 900,
      "display": { "type": "log", "maxLines": 1000 }
    }]
  }]
}
```

## 그래프 (5.2.0)

그래프를 쓰는 팩에는 `"minApp": "5.2.0"`을 적으세요. 더 오래된 앱은 "JetDeck 5.2.0 이상이 필요해요"라며 팩 전체를 거부해요.

그래프 항목은 **읽기 전용** 명령을 되풀이해서 실행하고, 읽은 숫자를 선 그래프로 그려요. 보통의 `exec` 항목에 `"display": { "type": "chart", ... }`를 쓰면 돼요.

* 사용자가 **시작**·**멈춤**·**일시정지**·**지우기**를 눌러요. 데이터는 앱 메모리에만 있고 파일에는 쓰지 않아요.
* **화면을 나가거나 연결을 끊거나 앱을 닫으면 멈춰요.** 한 번 읽을 때마다 스스로 끝나는 짧은 명령이라 Device에 남는 것이 없어요.
* 그래프에서 못 쓰는 것: `exec`가 아닌 `mode`, `fields`, `params`, `sudo`, `preview`, `read`가 아닌 `risk`. 앱이 명령을 읽기 전용으로 **증명**해야 하고, 못 하면 항목이 빠져요(경고로 끝나지 않아요). `auto: true`는 화면을 열 때 시작하고, 팩당 자동 실행 5개 한도에 들어가요.
* 규칙: 앞 읽기가 안 끝났으면 건너뛰어요. 읽기가 느리면 간격을 늘려요(최대 60초). 연속 5번 실패하면 멈춰요. 한도: 팩당 5개, 앱 전체 10개.

| 필드 | 필수 | 설명 |
|---|---|---|
| `every` | | 읽는 간격(초). 기본 2. 직접 설치하는 팩은 최소 1, 공식 팩은 0.5, 최대 60 |
| `points` | | 화면에 남기는 점 수. 10~3600, 기본 300 |
| `unit` | | 단위 글자, 8자 이내 |
| `min` / `max` | | 세로 범위. 없으면 앱이 정해요 |
| `match` 또는 `split` | 둘 중 하나 | `match`: 출력 한 줄마다 적용하는 정규식(표와 같은 제한). `split`: `ws`·`tab`·`csv`, 첫 데이터 줄을 칸으로 나눠요 |
| `skip` | | `split`과 함께: 건너뛸 첫 줄 수 |
| `perLine` 또는 `series` | 둘 중 하나 | `perLine`(`match`와): 맞는 줄마다 선 하나, `{ "label", "value", "scale" }`. `series`(최대 8): 고정된 선 목록, `[{ "label", "key" 또는 "col", "scale" }]` |

* `value`는 숫자가 들어 있는 `match` 묶음 번호예요(첫 묶음 = 1). `perLine.label`의 `{1}`은 첫 묶음 값이에요. 이 글자는 영문자·숫자·`_ . -`만, 20자까지 받아요. 다른 글자가 있는 줄은 버려요.
* `series[].key`는 `match`와 함께 쓰고, 이때 `match`에는 묶음이 **정확히 2개**(이름표, 값) 있어야 해요. `series[].col`은 `split`과 함께 써요(1~50번째 칸).
* `scale`은 곱하기예요(기본 1). 예: `45000`에 `0.001`이면 `45`. 유한한 수만 쓰고, 곱한 뒤 ±1e9 안이어야 해요.
* `timeout`은 한 번 읽는 최대 시간이에요. 기본 10, 최대 30.
* 읽을 숫자가 없으면 카드에 "읽을 수 있는 숫자가 없어요"와 마지막 출력 한 줄이 나와서 식을 고치는 데 도움이 돼요.

(예제 JSON은 위 영어 문서와 같아요. `docs/plugins/examples/examples.jdpack.json`에도 있어요.)

## 탐색기 배지 (5.3.0)

배지를 쓰는 팩에는 `"minApp": "5.3.0"`을 적으세요. 더 오래된 앱은 팩 전체를 거부해요.

배지는 **탐색기**의 파일·폴더 옆에 작은 표시를 붙여요. 폴더를 열면 JetDeck이 배지 명령을 Device에서 **저절로**(클릭 없이) 실행하고 출력을 읽어요. 배지는 플러그인 안이 아니라 팩 **맨 위** 필드(`badges`)예요. 배지만 있는 팩(`"plugins": []`)도 돼요.

* 명령은 **앱이 읽기 전용으로 증명**해야 해요. 팩을 읽을 때 한 번, 실행 직전에 실제 폴더를 채워서 한 번 더 확인해요. 증명하지 못하면 배지가 빠지거나(읽을 때), 말없이 건너뛰어요(실행할 때, 예: `~/.ssh`).
* 입력 자리는 `{dir}` 하나뿐이에요. 내가 연 폴더의 절대 경로이고, 따옴표 밖의 낱말로 쓰세요(명령 이름 자리 금지). 따옴표는 JetDeck이 붙여요.
* 표시는 항목당 최대 2개. 색은 앱이 정하고(`tone`) 팩은 못 정해요. 마우스를 올리면 `text`가 보여요. 안에 표시가 있는 항목이 있으면 폴더에 `●`가 붙어요(`"folderDot": false`로 끔).
* **끄는 스위치.** 플러그인 관리의 배지가 있는 팩마다 **탐색기 배지** 스위치가 있어요. 자동 실행만 멈추고 팩은 켜 둔 채예요. `--safe-mode`는 외부 팩과 그 배지를 모두 무시해요.
* 내장 Git 표시는 그대로예요. 공식 `devtools` 팩의 `git` 배지가 켜져 있으면 탐색기가 내장 Git 호출을 건너뛰어서, 같은 표시가 두 번 그려지거나 두 번 실행되지 않아요.

| 필드 | 필수 | 설명 |
|---|---|---|
| `id` | ○ | 팩 안에서 유일 |
| `label` | ○ | 글자. 관리 창·허용 창에 보이는 이름 |
| `cmd` | ○ | `{dir}`가 정확히 하나 있는 읽기 전용 명령. 2000자 이내 |
| `shell` | | `sh`(기본) 또는 `bash-i` |
| `separator` | | `line`(기본) 또는 `nul` — 출력 레코드를 나누는 방법 |
| `root` | | `dir`(기본): 출력의 경로는 연 폴더 기준. `line1`: 출력 첫 줄이 기준 폴더의 절대 경로(예: Git 저장소 최상위)이고 나머지는 그 기준. 기준 폴더 안의 하위 폴더는 다시 묻지 않아요 |
| `match` | ○ | 레코드마다 적용하는 정규식 (표와 같은 제한) |
| `code`, `path` | ○ | `match`의 서로 다른 묶음 번호: 상태 코드와 파일 경로 |
| `codes` | ○ | `{ "<코드>": { "show", "text", "tone" } }`, 1~30개. 코드는 1~2글자, `show`는 보이는 1~2글자, `tone`은 `info`·`ok`·`warn`·`bad`·`dim`. **적힌 코드만 표시해요** |
| `tag` | | `{ "match": "정규식" }`(묶음 1개). 맞는 첫 레코드의 묶음(40자 이내)을 기준 폴더 이름 옆에 보여요(예: 브랜치) |
| `folderDot` | | 기본 true |
| `ttl` | | 같은 기준 폴더를 다시 읽기까지 초. 3~300, 기본 5 |
| `timeout` | | 한 번 실행하는 최대 시간. 1~15초, 기본 10 |

실행할 때 규칙: 연결당 배지는 한 번에 하나(새 요청이 기다리는 요청을 대신해요), 결과는 `ttl` 동안 기억, 시간 초과가 연속 3번이면 그 접속 동안 배지를 멈춰요("느려서 멈췄어요"), 레코드 5000개·출력 1MB·레코드당 4096자까지, `..`나 제어 문자가 든 경로는 버려요. 한도: 팩당 배지 2개(공식 4개).

Git 저장소에는 가드가 하나 더 있어요. **저장소 자신의 설정이 프로그램을 실행할 수 있게 되어 있으면 JetDeck은 Git을 실행하지 않고**(폴더에 이유가 담긴 ⚠ 표시가 떠요), 훅·서명 프로그램·페이저를 꺼요. [security.md](security.md)를 보세요. 이 가드는 `git`을 실행하는 모든 팩 항목에도 적용돼요.

예(공식 Git 상태 배지)는 위 영어 부분과 같아요. `.py`·`.sh` 파일에 표시를 붙이는 작은 예도 영어 부분에 있고, 예제 팩(`examples`)에도 들어 있어요.

## 위험도

JetDeck은 팩에 적힌 `risk`를 **믿지 않아요.** 모든 선택지 조합의 명령을 분석해서 둘 중 **높은 쪽**을 써요.

* `read` — 읽기 전용임이 증명된 명령이에요(허용된 명령·옵션 목록과 작은 셸 해석기로 확인). 물어보지 않고 실행할 수 있어요.
* `change` — 읽기 전용임을 증명하지 못한 모든 명령. 먼저 물어봐요.
* `danger` — 삭제, 디스크, 전원, 패키지 설치·삭제, 외부로 보내기, `sudo`, 다른 셸 실행, 민감한 경로. 빨간 확인창으로 물어봐요.

`read`라고 적었는데 앱 계산이 더 높으면 항목은 남고, 앱이 높은 위험도를 쓰며, 창에 경고가 보여요. **규칙: 명령이 실제로 하는 일대로 적고, 모르겠으면 `change`.**

## 호환

5.x 동안 `format: 1`은 그대로예요. 새 5.x 버전은 필드를 **추가만** 해요. 추가된 기능을 쓰려면 `minApp`을 적으세요.

5.0.0 앱이 5.1 팩을 열면 `stream`·`log`·`fields`를 쓴 항목은 숨기고("새 버전 앱이 필요해요"), `minApp`이 더 높으면 팩 전체를 거부해요. 5.1 앱이 `chart`를 쓴 5.2 팩을 열 때도 같아요. 더 위험한 방식으로 실행하는 일은 없어요. 5.0·5.1 팩은 5.2에서 그대로 동작해요. 마찬가지로 5.2 앱은 `minApp` 5.3.0인 팩을 거부하고, `minApp` 없이 `badges`를 쓴 팩의 `badges`는 무시해요(표시도 위험도 없어요). 5.0~5.2 팩은 5.3에서 그대로 동작해요. 5.3 앱은 `minApp` 5.4.0인 팩을 거부하고, `minApp` 없이 `stopGrace`를 쓴 팩의 `stopGrace`는 무시해요(예전처럼 3초 뒤 멈춰요). 5.0~5.3 팩은 5.4에서 그대로 동작해요.
