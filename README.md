## ⬇ 다운로드

**<https://dawnilove.github.io/JetDeck/>** 에서 받으세요. 설치 방법, 사용법, 화면, 이전 버전도 모두 그곳에 있어요.

- **Windows 10 / 11** — 설치 파일 또는 포터블. "PC 보호" 창이 뜨면 **추가 정보 → 실행**
- **Linux (x64)** — AppImage, `chmod +x` 후 실행
